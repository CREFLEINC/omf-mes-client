# 작업 완료 보고 — 이슈 닫을 때 코멘트 양식

운영 규칙 §2-5.3. 이슈를 닫으며 다는 코멘트는 아래 형식을 따른다. `uiux→client` 착수 이슈였다면 「미결 처리 결과」·「어긋남」 절을 반드시 포함한다(`docs/uiux-handoff.md` §6).

```
작업 완료 보고

- PR: <링크>
- 검증 수준: <중요 | 보통 | 낮음>
- 검증: <실행한 명령과 결과 요약 — 예: pnpm typecheck 통과, pnpm test 통과(전체), pnpm mock:smoke 통과>
- 기존 실패: <있었으면 이슈 번호와 함께 — 예: #204 TZ 관련 9건, 이번 작업과 무관>

미결 처리 결과 (uiux→client 이슈에만)
- <항목> → <처리 방법(만들지 않음/자리표시 상수/비활성+사유)>. <한 줄 설명>

어긋남 (있었으면)
- <실측 결과와 어느 쪽을 따랐는지, 그 이유>. <검토 요청 번호>
```

값은 전부 합성 예시를 쓴다. 실제 사번·품목코드·LOT 번호·거래처 코드 등은 여기 들어가면 안 된다 — `CLAUDE.md` 공개 저장소 경계.
