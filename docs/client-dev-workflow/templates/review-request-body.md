# 검토 요청 이슈 본문 양식

`references/review-request.md`가 정본이다. 설계 저장소(`CREFLEINC/omf-mes`, 비공개)에 올리는 이슈 본문에 쓴다 — 비공개 저장소이므로 스펙 본문 인용이 허용된다.

```
## 어느 화면/계약인가

<화면 ID·이름> / <관련 엔드포인트>

## 무엇이 어긋났는가

- 스펙(<경로·개정일>)은: <서술>
- 계약(<버전>)은: <서술>
- 실측: <실제로 확인한 방법과 결과>

## 우리가 지금 어떻게 처리 중인가

<보류 중이면 그 사실 / 임시로 한쪽을 따라 진행 중이면 그 사실과 이유>

## 무엇을 정해 주면 되는가

<좁혀서 묻는다 — 예: "A(스펙)와 B(계약) 중 계약대로 B가 맞습니까?">

## 참고

- 클라이언트 저장소 이슈: <번호>
- 확인 시점: <설계 저장소 참조 클론의 HEAD 커밋·일시>
```
