# 화면 PR 점검표

화면을 새로 만들거나 구성을 바꾼 PR 본문에 붙인다. 규칙 번호는 `docs/screen-composition.md`를 따른다.

## 유형

- 화면 번호와 이름:
- 유형(T-…):
- 판정 근거(업무 이슈와 절차):
- 이탈한 규칙과 근거(없으면 「없음」):

## 자동 검사

- [ ] `pnpm ui:check` 새 위반 0 (줄어든 기준선: 건)
- [ ] `pnpm ui:probe -- <경로>` 검증 크기에서 P-1~P-5 결과 첨부 (캡처 경로:)

## 사람 확인

- [ ] 선택 결과가 목록 아래에 추가되지 않는다 (C-2)
- [ ] 영역마다 채움 버튼 하나, 유형별 위치 (C-3)
- [ ] 「준비 중」 버튼, 늘 잠긴 칸 없음 (C-4)
- [ ] 두 단계 이상이면 단계 표시와 「남은 일」 (C-5)
- [ ] 확정 전 확인과 완료 후 다음 작업 버튼 (C-9)
- [ ] 목록 행과 카드가 객체별 필드 정의를 따른다 (C-10)
- [ ] 문구가 C-13을 따른다
