## 기기 등록

**사용 시점** — 단말을 처음 켰을 때, 또는 등록이 만료되었을 때. 단말 한 대에 한 번만 수행합니다.

**사전 준비 사항** — 관리자가 발급하는 **등록 QR**. 관리자가 관리웹의 시스템 설정에서 단말을 선택해 화면에 표시해 줍니다.

등록하지 않은 단말은 다른 화면으로 이동할 수 없습니다. 화면에 다음과 같이 표시됩니다.

> **이 기기는 아직 등록되지 않았습니다**
> 관리자 화면의 등록 QR을 스캔하세요.
> 등록은 관리자가 관리웹 > 시스템 > 설정에서 만듭니다.

아래쪽에는 이 단말의 모델과 운영체제 버전이 함께 표시됩니다. 관리자에게 알려야 할 때 여기에서 확인하세요. 단말이 해당 정보를 읽지 못하면 `기기 정보를 읽지 못했습니다`로 표시됩니다.

### 순서

1. 관리자에게 등록 QR을 띄워 달라고 요청하세요.
2. 단말 화면에 카메라가 켜집니다. 준비되는 동안 `카메라를 준비하는 중입니다`가 표시됩니다.
3. 관리자 화면의 QR을 카메라로 비춥니다.
4. 인식되면 `등록되었습니다`와 함께 **단말 코드**가 표시됩니다.
5. **관리자가 알려 준 단말 코드와 같은지 직접 확인하세요.** 다른 QR을 읽어도 단말은 이를 구분하지 못합니다. 이를 확인할 수 있는 사람은 작업자가 유일합니다.
6. 이어서 `작업자 정보를 받는 중입니다`가 표시됩니다. **이 문구가 사라질 때까지 기다린 뒤 현장으로 나가세요.** 작업자 목록을 미리 받아 두어야 통신이 약한 곳에서도 사번을 확인할 수 있습니다.

### 표시되는 메시지

| 메시지                                          | 조치                                                                                                 |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `연결된 상태에서 등록해야 합니다`               | 등록은 서버 확인을 받아야 완료됩니다. 연결되는 곳으로 이동해 **다시 시도**를 누르세요                |
| `카메라 권한이 없어 등록 QR을 읽을 수 없습니다` | 단말 설정에서 카메라 권한을 허용한 뒤 **다시 시도**를 누르세요                                       |
| `이 기기에서 카메라 인식을 쓸 수 없습니다`      | 카메라 문제입니다. 관리자에게 알려 주세요                                                            |
| `등록 정보가 만료됐습니다`                      | 관리자에게 새 QR을 요청하세요. 관리자가 새로 발급하면 이전에 등록된 단말은 모두 다시 등록해야 합니다 |

## 사번 확인

**사용 시점** — 기기 등록을 마친 뒤 한 번, 그리고 **교대할 때마다**.

**필요 사유** — 이 단말에서 남기는 모든 기록이 여기에서 입력한 사번으로 남습니다. 사번을 변경하지 않으면 내가 한 작업이 이전 사용자의 이름으로 기록됩니다.

### 순서

**1. 사번을 입력하세요**

화면 가운데에 숫자 키패드가 있습니다. 여기에 사번을 입력합니다.

![사번 확인 화면. 위에 사번 입력란, 그 아래 1부터 0까지의 숫자 키패드와 모두 지우기 버튼, 맨 아래 확인 버튼](images/공통-01-사번확인.png)

- `←`는 마지막 한 자를 지웁니다.
- **모두 지우기**는 입력한 값을 전부 지웁니다.

**2. 확인을 누르세요**

이름과 사번이 표시되면 맞는지 확인하세요.

![사번 확인을 마친 화면. 홍길동 · 100027과 이 기기의 기록은 이 사번으로 남습니다라는 안내, 사번 바꾸기와 작업 목록으로 버튼](images/공통-02-사번입력.png)

**3. 작업 목록으로를 누르세요**

작업 화면 목록이 열립니다.

### 교대 시

**작업 목록에서 단말의 뒤로가기를 한 번 누르면** 이 화면으로 이동합니다. 여기에서 **사번 바꾸기**를 누르고 새 사번을 입력하세요.

이 화면에서 뒤로가기를 한 번 더 누르면 앱이 종료됩니다.

### 표시되는 메시지

| 메시지                                        | 조치                                                                                                                                 |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `등록되지 않았거나 재직 중이 아닌 사번입니다` | 사번을 다시 확인하세요. 맞는데도 같은 메시지가 표시되면 관리자에게 알려 주세요                                                       |
| `작업자 정보를 아직 받지 못했습니다`          | 단말이 작업자 목록을 아직 받지 못했습니다. 연결되는 곳에서 잠시 기다린 뒤 다시 시도하세요. 이 상태에서는 **확인**이 눌리지 않습니다 |

앞은 사번이 틀린 경우이고, 뒤는 단말이 아직 준비되지 않은 경우입니다. 조치가 서로 다릅니다.

## 전송 실패한 기록

**사용 시점** — 화면 위에 `전송 실패`가 표시되었을 때. 작업 목록 맨 아래 **전송 상태**에서도 들어올 수 있습니다.

**대상 기록** — 단말이 전송은 했으나 **서버가 받지 않은** 기록입니다. 화면 위에 다음과 같이 적혀 있습니다.

> 보냈지만 등록되지 않은 기록입니다. 다시 보내지 않습니다.

`전송 대기`와 다릅니다. 대기는 연결되면 자동으로 전송되지만, 이 목록의 기록은 **기다려도 전송되지 않습니다.**

실패한 기록이 없으면 다음과 같이 표시됩니다.

![전송 실패한 기록이 없습니다라는 안내만 있는 화면](images/공통-05-전송실패없음.png)

### 화면에 표시되는 내용

기록마다 세 가지가 표시됩니다.

- 무슨 기록이었는지 (예: `입하 등록`, `설비 점검`)
- `2026-09-10 09:14에 적음` — 언제 기록한 것인지. 다시 기록하려면 당시 작업 내용을 확인해야 합니다
- 되돌아온 이유

| 되돌아온 이유                             | 뜻                                                                                       |
| ----------------------------------------- | ---------------------------------------------------------------------------------------- |
| `적은 내용에 문제가 있습니다.`            | 입력한 값이 서버 검사를 통과하지 못했습니다. 같은 값으로 다시 전송해도 결과가 같습니다   |
| `다른 곳에서 먼저 바뀌었습니다.`          | 다른 단말이나 관리웹에서 같은 대상을 먼저 변경했습니다. 현재 상태를 보고 다시 판단하세요 |
| `지금 상태에서는 할 수 없는 일입니다.`    | 대상이 이미 다음 단계로 넘어가 있습니다                                                  |
| `앞 기록이 가지 못해 붙을 곳이 없습니다.` | 한 묶음으로 전송한 기록 중 앞의 것이 실패해 뒤의 것도 함께 빠졌습니다                    |
| `보냈지만 등록되지 않았습니다.`           | 위 어디에도 해당하지 않는 경우                                                           |

### 순서

1. 목록에서 실패한 기록과 이유를 확인하세요.
2. 이유에 따라 해당 작업 화면으로 이동해 **다시 작업하세요.** 이 화면에는 다시 전송하는 버튼이 없습니다.
3. 처리를 마쳤으면 **목록에서 내리기**를 눌러 삭제합니다.

**목록에서 내려도 그 기록이 서버로 전송되지는 않습니다.** 확인했다는 표시에 그칩니다.
