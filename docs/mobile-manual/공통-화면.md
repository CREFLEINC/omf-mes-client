# 공통 화면

작업 화면에 들어가기 전에 거치는 두 화면과, 어느 작업에서도 쓰이는 기록 확인 화면입니다.

---

## 기기 등록

**언제 쓰나** — 단말을 처음 켰을 때, 또는 등록 정보가 만료됐을 때. 단말마다 한 번만 합니다.

**누가 하나** — 작업자가 단말에서 조작하되, 등록 QR은 관리자가 관리웹에서 만들어 줍니다.

### 화면이 보여 주는 것

단말이 등록되어 있지 않으면 다른 화면으로 갈 수 없고 이 화면만 열립니다. 화면에는 다음이 뜹니다.

- `이 기기는 아직 등록되지 않았습니다`
- `관리자 화면의 등록 QR을 스캔하세요.`
- `등록은 관리자가 관리웹 > 시스템 > 설정에서 만듭니다.`

세 번째 줄은 작업자가 관리자에게 무엇을 요청해야 하는지 알 수 있도록 적어 둔 것입니다.

아래쪽에는 **기기 정보**가 함께 보입니다. 단말 모델과 운영체제 판입니다. 단말이 그 값을 내놓지 못하면 `기기 정보를 읽지 못했습니다`로 표시합니다.

### 절차

1. 관리자에게 등록 QR을 요청합니다. 관리자는 관리웹의 시스템 설정에서 단말을 골라 QR을 띄웁니다.
2. 단말 화면에 뜬 카메라로 그 QR을 비춥니다. 카메라가 준비되는 동안 `카메라를 준비하는 중입니다`가 보입니다.
3. QR을 읽으면 `등록되었습니다`가 뜨고, 무엇으로 등록됐는지 **단말 코드**가 함께 보입니다.
4. `관리자가 안내한 단말 코드와 같은지 확인하세요`를 따라 관리자가 알려 준 코드와 대조합니다. 틀린 QR을 읽었더라도 기계는 그것을 알아낼 수 없습니다. 확인할 수 있는 것은 사람뿐입니다.
5. 등록이 끝나면 곧바로 `작업자 정보를 받는 중입니다`가 뜹니다. 작업자 목록을 받는 과정이며, **끝날 때까지 현장으로 들어가지 마십시오.** 이 목록을 받아 두어야 통신이 약한 자리에서도 사번을 확인할 수 있습니다.

### 막히는 경우

| 화면에 뜨는 말                                  | 뜻과 할 일                                                                                         |
| ----------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `연결된 상태에서 등록해야 합니다`               | 등록은 서버 확인을 받아야 끝납니다. 연결이 되는 자리로 옮겨 `다시 시도`를 누르십시오.              |
| `카메라 권한이 없어 등록 QR을 읽을 수 없습니다` | 단말 설정에서 카메라 권한을 허용한 뒤 `다시 시도`를 누르십시오.                                    |
| `이 기기에서 카메라 인식을 쓸 수 없습니다`      | 카메라 모듈이나 설정 문제입니다. 관리자에게 알리십시오.                                            |
| `등록 정보가 만료됐습니다`                      | 관리자에게 새 QR을 요청하십시오. 관리자가 토큰을 다시 발급하면 이전에 등록된 단말은 모두 끊깁니다. |

## 사번 확인

**언제 쓰나** — 기기 등록을 마친 뒤, 그리고 교대할 때마다.

**왜 하나** — 이 단말에서 하는 모든 기록이 여기서 넣은 사번으로 남습니다. 단말 하나를 여러 사람이 번갈아 쓰기 때문에, 사번을 바꾸지 않으면 앞 사람 이름으로 기록이 쌓입니다.

### 절차

1. 화면 가운데 **사번** 칸과 숫자판이 보입니다. 숫자판으로 사번을 넣습니다.
   - `한 자 지우기`로 마지막 한 자를 지웁니다.
   - `모두 지우기`로 전부 지웁니다.
2. **확인**을 누릅니다.
3. 확인되면 `현재 작업자`에 이름과 사번이 함께 뜨고, `이 기기의 기록은 이 사번으로 남습니다.`가 보입니다.
4. **작업 목록으로**를 누르면 화면 목록이 열립니다.

교대할 때는 이 화면에서 **사번 바꾸기**를 누르고 다시 넣습니다.

### 막히는 경우

| 화면에 뜨는 말                                | 뜻과 할 일                                                                                                                                       |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `등록되지 않았거나 재직 중이 아닌 사번입니다` | 넣은 사번이 작업자 목록에 없습니다. 사번을 다시 확인하고, 맞는데도 같은 말이 뜨면 관리자에게 알리십시오.                                         |
| `작업자 정보를 아직 받지 못했습니다`          | 단말이 작업자 목록을 아직 받지 못했습니다. 연결이 되는 자리에서 잠시 기다린 뒤 다시 시도하십시오. 이 상태에서는 **확인** 단추가 눌리지 않습니다. |

두 문구는 작업자가 할 수 있는 일이 서로 달라 나눠 두었습니다. 앞의 것은 사번이 틀린 것이고, 뒤의 것은 단말이 아직 준비되지 않은 것입니다.

## 전송 실패한 기록

**언제 쓰나** — 위쪽 연결 표시에 `전송 실패`가 붙었을 때. 작업 목록 맨 아래에서도 들어갈 수 있습니다.

**무엇이 담기나** — 단말이 보내기는 했으나 서버가 받지 않은 기록입니다. 화면 위에 이렇게 적혀 있습니다.

> 보냈지만 등록되지 않은 기록입니다. 다시 보내지 않습니다.

`전송 대기`와는 다릅니다. 대기는 연결되면 가지만, 이 목록의 것은 기다려도 가지 않습니다. 무엇이 잘못됐는지 확인하고 필요하면 그 작업을 다시 해야 합니다.

### 화면이 보여 주는 것

기록마다 다음이 보입니다.

- 어떤 기록이었는지 (예: `입하 등록`, `설비 점검`)
- `2026-09-10 09:14에 적음` — 언제 적은 것인지. 다시 적으려면 그때를 알아야 합니다.
- 되돌아온 사유

| 사유 문구                                 | 뜻                                                                                            |
| ----------------------------------------- | --------------------------------------------------------------------------------------------- |
| `적은 내용에 문제가 있습니다.`            | 넣은 값이 서버 검증을 통과하지 못했습니다. 같은 값으로 다시 보내도 같은 결과입니다.           |
| `다른 곳에서 먼저 바뀌었습니다.`          | 다른 단말이나 관리웹에서 같은 대상을 먼저 바꿨습니다. 현재 상태를 확인하고 다시 판단하십시오. |
| `지금 상태에서는 할 수 없는 일입니다.`    | 대상이 이미 다음 단계로 넘어가 있습니다.                                                      |
| `앞 기록이 가지 못해 붙을 곳이 없습니다.` | 한 묶음으로 보낸 기록 중 앞의 것이 실패해 뒤의 것도 함께 빠졌습니다.                          |
| `보냈지만 등록되지 않았습니다.`           | 위 어느 것에도 들지 않는 경우입니다.                                                          |

여러 건이 한 묶음으로 나간 작업에서는 `앞 기록이 실패해 이 기록도 보내지 못했습니다`가 함께 붙습니다.

### 절차

1. 목록에서 실패한 기록과 사유를 확인합니다.
2. 사유에 따라 해당 작업 화면으로 가서 다시 합니다. 이 화면에는 다시 보내는 단추가 없습니다.
3. 처리를 마쳤으면 **목록에서 내리기**를 눌러 목록에서 지웁니다. 내려도 기록이 서버에 가지는 않습니다. 확인했다는 표시일 뿐입니다.

실패한 기록이 없으면 `전송 실패한 기록이 없습니다.`가 보입니다.
