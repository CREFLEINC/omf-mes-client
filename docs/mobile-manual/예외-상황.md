## 라벨이 안 읽힙니다

찢어졌거나 더러워서 스캐너가 못 읽습니다.

**→ 화면의 `직접 입력`을 누르고 번호를 손으로 치세요.**

![직접 입력을 누른 뒤. 방금 그 스캔 입력란이 손으로 칠 수 있게 열리고 아래 버튼이 넣기로 바뀌었다](images/공통-03-직접입력.png)

입력란이 새로 생기지 않습니다. **방금 그 스캔 자리**가 열립니다. 다 치면 아래 버튼을 누르세요. 버튼 이름은 화면마다 조금씩 다릅니다([표는 여기](README.md#2-라벨이-안-읽힐-때--직접-입력)).

**치는 도중에 스캐너로 읽으면 스캔한 값이 이깁니다.** 치던 것은 지워집니다.

### 라벨이 아예 없을 때

| 무엇의 라벨이 없나 | 이렇게 하세요                                                                          |
| ------------------ | -------------------------------------------------------------------------------------- |
| 들어온 자재        | [입하 등록](01-자재창고.md#입하-등록)에서 **LOT 번호 없음** → 대체 LOT 사유를 고릅니다 |
| 나중에 찾았다      | [자재LOT 스캔·등록](01-자재창고.md#자재lot-스캔등록)으로 뒤에 채웁니다                 |
| 위치               | 위치를 관리하지 않는 창고는 스캔하지 않고 목록에서 고릅니다                            |

### 설비는 직접 입력이 없습니다

[설비 점검](05-설비.md#설비-점검)과 [설비 고장 보고](05-설비.md#설비-고장-보고)에는 직접 입력이 없습니다. **목록에서 고르기**를 쓰세요. 손으로 쳐도 결국 같은 목록에서 찾기 때문에 더할 것이 없습니다.

## 스캔했는데 못 찾았다고 합니다

대부분의 화면은 **짧은 오류음**을 함께 냅니다. 단말을 허리에 매단 채 읽는 자리가 많아 소리로도 알리는 것입니다.

| 화면에 나오는 말                                      | 뜻                                     |
| ----------------------------------------------------- | -------------------------------------- |
| 무엇을 찾지 못했다는 말                               | 그 번호가 등록되어 있지 않습니다       |
| `자재 LOT 번호는 34자리입니다`                        | 덜 읽었거나 더 읽었습니다. 다시 대세요 |
| `이 라인의 LOT 이 아닙니다. RM-1001 을(를) 집으세요.` | 있는 번호지만 지금 줄의 것이 아닙니다  |
| `이 지시의 LOT 이 아닙니다`                           | 적치 지시가 가리키는 자재가 아닙니다   |
| `이 라인의 품목이 아닙니다`                           | 품목 자체가 다릅니다                   |

> **오류음이 안 나는 화면이 넷 있습니다** — 재고 이동 · 실물 카운트 · 재생재 등록 · 긴급 IQC 생략 요청. 이 넷을 쓸 때는 **스캔한 뒤 화면을 꼭 보세요.**

## 수량이 안 맞습니다

### 받은 것이 예정과 다를 때 (입하)

숫자를 넣는 즉시 화면이 갈라 줍니다. **견주는 기준은 발주 총량이 아니라 `남은 예정`** 입니다.

| 판정 | 화면이 하는 일                                                        |
| ---- | --------------------------------------------------------------------- |
| 맞음 | 바로 **입하 등록**을 누르면 끝                                        |
| 초과 | 같은 화면에 **정량분·초과분 나누는 자리**가 열립니다                  |
| 부족 | **더 올 물량이 있는지** 묻습니다 — 트럭과 명세서를 본 사람이 정합니다 |

![수량 부족 부분. 발주·누적·이번 도착·남은 네 숫자와 계속 등록, 보류로 받고 오류 등록 두 버튼](images/01-입하등록-7-부족.png)

**부족한데 이번이 마지막이면** `보류로 받고 오류 등록`을 고르세요. **먼저 받아 두는 것이 순서입니다** — 등록하지 않고 넘어가면 오류를 붙일 자리가 생기지 않습니다.

### 그 밖의 수량 문제

| 겪는 일                      | 화면이 하는 일                                                         |
| ---------------------------- | ---------------------------------------------------------------------- |
| 라벨 수량과 줄 수량이 다르다 | 알리기만 하고 **막지 않습니다**. 라벨은 최초 납품 때 값입니다          |
| 인식표 수량과 실물이 다르다  | 알리기만 하고 **막지 않습니다**. 실물대로 받는 것이 맞습니다           |
| 받은 양이 출고량보다 적다    | **차이 사유를 꼭 골라야** 합니다                                       |
| 받은 양이 출고량보다 많다    | **막힙니다**                                                           |
| 재고보다 많이 옮기려 한다    | **막힙니다**                                                           |
| 실물이 하나도 없다           | 실물 카운트에서 `0`을 적으세요. **빈칸은 「아직 안 셌다」는 뜻입니다** |

## 가야 할 자리에 못 넣습니다

[적치·입고 완료](01-자재창고.md#적치입고-완료)에서 위치를 스캔했더니 막혔습니다.

![권장 위치가 아닌 자리를 스캔했을 때. 권장 위치가 아닙니다라는 빨간 안내와 임시 위치 적재로 갑니다라는 링크](images/07-적치-4-권장아님.png)

| 화면에 나오는 말                                | 막히나              | 이렇게 하세요                                                 |
| ----------------------------------------------- | ------------------- | ------------------------------------------------------------- |
| `권장 위치 … 가 아닙니다`                       | **막힙니다**        | 링크를 따라 [임시 위치 적재](01-자재창고.md#임시-위치-적재)로 |
| `이 위치는 단일 품목만 보관합니다`              | **막힙니다**        | 같은 자리에 다른 품목이 이미 있습니다                         |
| `이 위치는 단일 LOT 만 보관합니다`              | **막힙니다**        | 같은 자리에 다른 LOT이 이미 있습니다                          |
| `수용량 500 · 현재 400 + 300`                   | 막지 않습니다       | 넘겨 둘지는 자리를 보는 사람이 정합니다                       |
| `품목은 냉장 보관인데 이 자리는 상온 입니다`    | 막지 않습니다       | 냉장 자리가 없어 상온에 두어야 하는 날이 있습니다             |
| `관리 위치가 없는 품목입니다. 여기 적치합니까?` | 확인하면 넘어갑니다 | **여기 적치합니다**를 누릅니다                                |

### 임시로 둘 때 꼭 알아 둘 것

- **이 화면은 작업을 끝내지 않습니다.** 정위치로 옮기는 일이 그대로 남습니다.
- 왜 임시로 두는지 **사유나 비고 중 하나는 꼭** 적어야 합니다.
- 목록에는 임시 유형으로 등록된 자리만 나옵니다. **목록에 없는 자리에 두어야 하면 `직접 입력`으로 코드를 치세요.**

## 보류라서 못 씁니다

품질 확인이 끝나지 않은 자재·제품입니다. 화면마다 다루는 방식이 **다릅니다.**

| 화면           | 보류된 것을          | 왜                                                                             |
| -------------- | -------------------- | ------------------------------------------------------------------------------ |
| 재고 이동      | **옮길 수 있습니다** | 자리를 옮기는 것은 쓰는 것이 아닙니다                                          |
| WIP 공정 이동  | **막습니다**         | 다음 공정에 넣으면 불량이 퍼집니다                                             |
| 자재 출고·피킹 | **집을 수 없습니다** | 라인에 들어가는 것이라 막습니다                                                |
| 제품 피킹      | **집을 수 없습니다** | 나가는 것이라 막습니다                                                         |
| 제품 입고·적치 | **받습니다**         | 들어오는 것을 막으면 물건이 갈 곳이 없습니다. 막히는 것은 뒤의 피킹·출하입니다 |

집을 수 없는 자리에서는 **사유와 해제 조건**을 함께 보여 줍니다 — 무엇을 하면 풀리는지 읽을 수 있습니다. 보류를 푸는 것은 품질에서 합니다.

`보류 사유를 확인하는 중입니다`나 `보류 사유를 확인하지 못했습니다`가 나오면, 사유를 **아직 못 받은** 것입니다. 사유가 없는 것과 다릅니다.

## 연결이 끊겼습니다

화면 위 표시가 `오프라인`으로 바뀝니다. 화면은 세 가지 중 하나로 움직입니다.

### 아예 못 들어가는 화면

![제품 피킹 화면. 오프라인이라 피킹할 수 없습니다라는 안내와 다시 시도 버튼](images/공통-06-오프라인차단.png)

**WIP 공정 이동 · 수리 왕복 스캔 · 제품 피킹** 셋입니다. 연결되는 자리로 옮긴 뒤 **다시 시도**를 누르세요.

다 해 놓고 저장에서 막히면 작업을 통째로 버리게 되기 때문에 들어가는 것 자체를 막습니다.

### 들어가지지만 목록을 못 받는 화면

무엇을 못 받았는지 화면이 말해 줍니다. 스캔한 것과 적은 것은 **그대로 둡니다.**

### 적어 두었다가 나중에 보내는 화면

![재생재 등록을 전송 대기에 넣었습니다라는 안내. 위쪽에 오프라인과 전송 대기 1이 보인다](images/공통-07-전송대기.png)

`완료`가 아니라 **`전송 대기`** 라고 말합니다. **아직 서버에 가지 않았다는 뜻입니다.** 몇 건 남았는지는 화면 위 표시로 봅니다.

> 긴급 요청이나 설비 고장처럼 **사람이 기다리는 기록**은 대기 중이라는 사실이 계속 떠 있습니다. 급하면 유선으로도 알려 주세요.

### 「연결을 확인하세요」가 나왔는데 연결은 멀쩡할 때

`도착 위치를 확인하지 못했습니다. 연결 문제가 아니니 담당자에게 알리세요.` 가 나오면 **연결 문제가 아닙니다.** 자리를 옮겨도 그대로입니다. 담당자에게 알려 주세요.

## 잘못 등록했습니다

**되돌리는 길이 있는 것과 없는 것이 갈립니다.**

| 기록               | 되돌릴 수 있나                     | 잘못했으면                              |
| ------------------ | ---------------------------------- | --------------------------------------- |
| 입하 오류 등록     | **없습니다**                       | 고치지 말고 새로 하나 더 적습니다       |
| 제품 피킹 확정     | **없습니다** (예약이 소진됩니다)   | 담당자에게 알립니다                     |
| 포장 재구성        | **없습니다**                       | 반대 방향으로 한 번 더 재구성합니다     |
| 긴급 IQC 생략 요청 | **없습니다** (취소·회수 안 됩니다) | 다시 올리고 승인자가 반려합니다         |
| 자재 출고 확정     | 되돌아올 수 있습니다               | 실패하면 물건 회수가 필요할 수 있습니다 |

되돌릴 수 없는 기록은 **저장 전에 한 번 더 묻습니다.**

![등록하면 고칠 수 없습니다라는 확인 창. 돌아가기와 등록합니다 두 버튼](images/공통-04-확인대화.png)

완료 버튼을 여러 번 눌러도 **기록은 한 건만** 나갑니다. 안심하고 누르세요.

## 화면이 안 열립니다

| 겪는 일                                   | 이유와 할 일                                                          |
| ----------------------------------------- | --------------------------------------------------------------------- |
| 아무 화면도 안 열리고 QR을 읽으라고 한다  | 단말이 아직 등록되지 않았습니다 → [기기 등록](공통-화면.md#기기-등록) |
| **확인** 버튼이 안 눌린다 (사번 화면)     | 작업자 목록을 아직 못 받았습니다. 연결되는 자리에서 잠깐 기다리세요   |
| 임시 위치 적재가 「지시를 가지고 오세요」 | 적치 화면에서 지시를 고른 뒤에 와야 합니다                            |
| 완료 버튼이 흐리다                        | 필수 항목이 남았습니다. 화면 아래에 무엇이 남았는지 나옵니다          |
| 목록이 비어 있다                          | 내 사번으로 온 지시만 나옵니다. 사번이 내 것인지 먼저 보세요          |

## 보냈는데 안 갔습니다

화면 위에 `전송 실패 N`이 붙었습니다. **`전송 대기`와 다릅니다** — 대기는 기다리면 가지만 이것은 **기다려도 가지 않습니다.**

→ [전송 실패한 기록](공통-화면.md#전송-실패한-기록)에서 이유를 확인하고, 해당 작업 화면에서 **다시 하세요.** 그 화면에는 다시 보내는 버튼이 없습니다.

| 되돌아온 이유                             | 다시 해도 되나                          |
| ----------------------------------------- | --------------------------------------- |
| `적은 내용에 문제가 있습니다.`            | 같은 값으로는 결과가 같습니다           |
| `다른 곳에서 먼저 바뀌었습니다.`          | 지금 상태를 보고 다시 판단하세요        |
| `지금 상태에서는 할 수 없는 일입니다.`    | 대상이 이미 다음 단계로 넘어가 있습니다 |
| `앞 기록이 가지 못해 붙을 곳이 없습니다.` | 앞의 것부터 해결해야 합니다             |

처리를 마쳤으면 **목록에서 내리기**로 지웁니다. 내려도 그 기록이 서버로 가지는 않습니다 — 확인했다는 표시일 뿐입니다.
