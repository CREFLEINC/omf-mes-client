## 라벨이 읽히지 않습니다

라벨이 찢어졌거나 오염되어 스캐너가 읽지 못합니다.

**→ 화면의 `직접 입력`을 누르고 번호를 직접 입력하세요.**

![직접 입력을 누른 뒤. 방금 스캔하려던 입력란이 직접 입력할 수 있게 바뀌고 아래 버튼이 넣기로 바뀌었다](images/공통-03-직접입력.png)

입력란이 새로 생기지 않습니다. **방금 스캔하려던 입력란**이 열립니다. 입력을 마치면 아래 버튼을 누르세요. 버튼 이름은 화면마다 조금씩 다릅니다([표는 여기](README.md#2-라벨이-읽히지-않을-때--직접-입력)).

**입력하는 도중에 스캐너로 읽으면 스캔한 값으로 바뀝니다.** 입력하던 내용은 지워집니다.

### 라벨이 아예 없을 때

| 어떤 라벨이 없는가 | 조치                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------- |
| 들어온 자재        | [입하 등록](01-자재창고.md#입하-등록)에서 **LOT 번호 없음** → 대체 LOT 사유를 선택합니다 |
| 나중에 찾았을 때   | [자재LOT 스캔·등록](01-자재창고.md#자재lot-스캔등록)으로 나중에 채웁니다                 |
| 위치               | 위치를 관리하지 않는 창고는 스캔하지 않고 목록에서 선택합니다                            |

### 설비 화면에는 직접 입력이 없습니다

[설비 점검](05-설비.md#설비-점검)과 [설비 고장 보고](05-설비.md#설비-고장-보고)에는 직접 입력이 없습니다. **목록에서 고르기**를 사용하세요. 직접 입력해도 결국 같은 목록에서 찾게 되므로 별도로 두지 않았습니다.

## 스캔했는데 찾지 못했다고 표시됩니다

대부분의 화면은 **짧은 오류음**을 함께 냅니다. 단말을 허리에 매단 채 읽는 경우가 많아 소리로도 알립니다.

| 화면에 표시되는 안내                                  | 뜻                                          |
| ----------------------------------------------------- | ------------------------------------------- |
| 무엇을 찾지 못했다는 안내                             | 그 번호가 등록되어 있지 않습니다            |
| `자재 LOT 번호는 34자리입니다`                        | 덜 읽었거나 더 읽었습니다. 다시 스캔하세요  |
| `이 라인의 LOT 이 아닙니다. RM-1001 을(를) 집으세요.` | 존재하는 번호이지만 현재 줄의 LOT이 아닙니다 |
| `이 지시의 LOT 이 아닙니다`                           | 적치 지시가 가리키는 자재가 아닙니다        |
| `이 라인의 품목이 아닙니다`                           | 품목 자체가 다릅니다                        |

> **오류음이 나지 않는 화면이 네 개 있습니다** — 재고 이동 · 실물 카운트 · 재생재 등록 · 긴급 IQC 생략 요청. 이 네 화면에서는 **스캔한 뒤 반드시 화면을 확인하세요.**

## 수량이 맞지 않습니다

### 받은 수량이 예정과 다를 때 (입하)

수량을 입력하는 즉시 화면이 정량분과 초과분을 나눠 줍니다. **비교 기준은 발주 총량이 아니라 `남은 예정`** 입니다.

| 판정 | 화면의 동작                                                             |
| ---- | ----------------------------------------------------------------------- |
| 맞음 | 바로 **입하 등록**을 누르면 완료                                        |
| 초과 | 같은 화면에 **정량분·초과분을 나누는 항목**이 열립니다                  |
| 부족 | **더 들어올 물량이 있는지** 확인합니다 — 차량과 명세서를 본 사람이 판단합니다 |

![수량 부족 부분. 발주·누적·이번 도착·남은 네 숫자와 계속 등록, 보류로 받고 오류 등록 두 버튼](images/01-입하등록-7-부족.png)

**부족한데 이번이 마지막 납품이라면** `보류로 받고 오류 등록`을 선택하세요. **먼저 받아 두는 것이 순서입니다** — 등록하지 않고 넘어가면 오류를 붙일 대상이 생기지 않습니다.

### 그 밖의 수량 문제

| 겪는 상황                        | 화면의 동작                                                            |
| -------------------------------- | ---------------------------------------------------------------------- |
| 라벨 수량과 줄 수량이 다를 때    | 안내만 하고 **막지 않습니다**. 라벨은 최초 납품 시점의 값입니다        |
| 인식표 수량과 실물이 다를 때     | 안내만 하고 **막지 않습니다**. 실물 기준으로 받는 것이 맞습니다        |
| 받은 수량이 출고량보다 적을 때   | **차이 사유를 반드시 선택해야** 합니다                                 |
| 받은 수량이 출고량보다 많을 때   | **막힙니다**                                                           |
| 재고보다 많이 옮기려 할 때       | **막힙니다**                                                           |
| 실물이 하나도 없을 때            | 실물 카운트에서 `0`을 입력하세요. **빈칸은 아직 세지 않았다는 뜻입니다** |

## 지정된 위치에 넣을 수 없습니다

[적치·입고 완료](01-자재창고.md#적치입고-완료)에서 위치를 스캔했으나 막혔습니다.

![권장 위치가 아닌 자리를 스캔했을 때. 권장 위치가 아닙니다라는 빨간 안내와 임시 위치 적재로 갑니다라는 링크](images/07-적치-4-권장아님.png)

| 화면에 표시되는 안내                            | 막히는가            | 조치                                                          |
| ----------------------------------------------- | ------------------- | ------------------------------------------------------------- |
| `권장 위치 … 가 아닙니다`                       | **막힙니다**        | 링크를 따라 [임시 위치 적재](01-자재창고.md#임시-위치-적재)로 |
| `이 위치는 단일 품목만 보관합니다`              | **막힙니다**        | 같은 위치에 다른 품목이 이미 있습니다                         |
| `이 위치는 단일 LOT 만 보관합니다`              | **막힙니다**        | 같은 위치에 다른 LOT이 이미 있습니다                          |
| `수용량 500 · 현재 400 + 300`                   | 막지 않습니다       | 초과해서 둘지는 현장을 보는 사람이 판단합니다                 |
| `품목은 냉장 보관인데 이 자리는 상온 입니다`    | 막지 않습니다       | 냉장 위치가 없어 상온에 두어야 하는 경우가 있습니다           |
| `관리 위치가 없는 품목입니다. 여기 적치합니까?` | 확인하면 넘어갑니다 | **여기 적치합니다**를 누릅니다                                |

### 임시로 둘 때 반드시 알아 둘 것

- **이 화면은 작업을 끝내지 않습니다.** 정위치로 옮기는 작업이 그대로 남습니다.
- 임시로 두는 이유를 **사유나 비고 중 하나는 반드시** 입력해야 합니다.
- 목록에는 임시 유형으로 등록된 위치만 표시됩니다. **목록에 없는 위치에 두어야 하면 `직접 입력`으로 코드를 입력하세요.**

## 보류 상태라 사용할 수 없습니다

품질 확인이 끝나지 않은 자재·제품입니다. 화면마다 처리 방식이 **다릅니다.**

| 화면           | 보류된 대상을        | 이유                                                                           |
| -------------- | -------------------- | ------------------------------------------------------------------------------ |
| 재고 이동      | **옮길 수 있습니다** | 위치를 옮기는 것은 사용하는 것이 아닙니다                                      |
| WIP 공정 이동  | **막습니다**         | 다음 공정에 넣으면 불량이 퍼집니다                                             |
| 자재 출고·피킹 | **집을 수 없습니다** | 라인에 투입되는 것이라 막습니다                                                |
| 제품 피킹      | **집을 수 없습니다** | 외부로 나가는 것이라 막습니다                                                  |
| 제품 입고·적치 | **받습니다**         | 들어오는 것을 막으면 물건이 갈 곳이 없습니다. 막히는 것은 이후의 피킹·출하입니다 |

집을 수 없는 화면에서는 **사유와 해제 조건**이 함께 표시됩니다 — 무엇을 해야 풀리는지 확인할 수 있습니다. 보류를 해제하는 것은 품질 부서에서 합니다.

`보류 사유를 확인하는 중입니다`나 `보류 사유를 확인하지 못했습니다`가 표시되면, 사유를 **아직 받지 못한** 것입니다. 사유가 없는 것과 다릅니다.

## 연결이 끊겼습니다

화면 위 표시가 `오프라인`으로 바뀝니다. 화면은 세 가지 중 한 가지로 동작합니다.

### 들어갈 수 없는 화면

![제품 피킹 화면. 오프라인이라 피킹할 수 없습니다라는 안내와 다시 시도 버튼](images/공통-06-오프라인차단.png)

**WIP 공정 이동 · 수리 왕복 스캔 · 제품 피킹** 세 화면입니다. 연결되는 곳으로 이동한 뒤 **다시 시도**를 누르세요.

작업을 모두 마친 뒤 저장 단계에서 막히면 처음부터 다시 해야 하기 때문에 진입 자체를 막습니다.

### 들어갈 수는 있으나 목록을 불러오지 못하는 화면

무엇을 불러오지 못했는지 화면에 안내됩니다. 스캔한 값과 입력한 내용은 **그대로 유지됩니다.**

### 저장해 두었다가 나중에 전송하는 화면

![재생재 등록을 전송 대기에 넣었습니다라는 안내. 위쪽에 오프라인과 전송 대기 1이 보인다](images/공통-07-전송대기.png)

`완료`가 아니라 **`전송 대기`** 로 표시됩니다. **아직 서버에 도달하지 않았다는 뜻입니다.** 몇 건이 남았는지는 화면 위 표시로 확인합니다.

> 긴급 요청이나 설비 고장처럼 **다른 사람이 기다리는 기록**은 대기 중이라는 안내가 계속 표시됩니다. 급한 경우 유선으로도 알려 주세요.

### 연결을 확인하라고 나오는데 연결에 문제가 없을 때

`도착 위치를 확인하지 못했습니다. 연결 문제가 아니니 담당자에게 알리세요.` 가 표시되면 **연결 문제가 아닙니다.** 위치를 옮겨도 동일합니다. 담당자에게 알려 주세요.

## 잘못 등록했습니다

**되돌릴 수 있는 기록과 없는 기록이 나뉩니다.**

| 기록               | 되돌릴 수 있는가                   | 잘못한 경우                             |
| ------------------ | ---------------------------------- | --------------------------------------- |
| 입하 오류 등록     | **없습니다**                       | 수정하지 말고 새로 하나 더 등록합니다   |
| 제품 피킹 확정     | **없습니다** (예약이 소진됩니다)   | 담당자에게 알립니다                     |
| 포장 재구성        | **없습니다**                       | 반대 방향으로 한 번 더 재구성합니다     |
| 긴급 IQC 생략 요청 | **없습니다** (취소·회수 불가)      | 다시 요청하고 승인자가 반려합니다       |
| 자재 출고 확정     | 되돌아올 수 있습니다               | 실패하면 물건 회수가 필요할 수 있습니다 |

되돌릴 수 없는 기록은 **저장 전에 한 번 더 확인합니다.**

![등록하면 고칠 수 없습니다라는 확인 창. 돌아가기와 등록합니다 두 버튼](images/공통-04-확인대화.png)

완료 버튼을 여러 번 눌러도 **기록은 한 건만** 전송됩니다. 중복으로 기록되지 않습니다.

## 화면이 열리지 않습니다

| 겪는 상황                                     | 이유와 조치                                                             |
| --------------------------------------------- | ----------------------------------------------------------------------- |
| 아무 화면도 열리지 않고 QR을 읽으라고 표시됨  | 단말이 아직 등록되지 않았습니다 → [기기 등록](공통-화면.md#기기-등록)   |
| **확인** 버튼이 눌리지 않음 (사번 화면)       | 작업자 목록을 아직 받지 못했습니다. 연결되는 곳에서 잠시 기다리세요     |
| 임시 위치 적재에 지시를 가지고 오라고 표시됨  | 적치 화면에서 지시를 선택한 뒤에 들어와야 합니다                        |
| 완료 버튼이 흐리게 보임                       | 필수 항목이 남았습니다. 무엇이 남았는지 화면 아래에 표시됩니다          |
| 목록이 비어 있음                              | 내 사번으로 배정된 지시만 표시됩니다. 사번이 내 사번인지 먼저 확인하세요 |

## 전송했는데 등록되지 않았습니다

화면 위에 `전송 실패 N`이 표시되었습니다. **`전송 대기`와 다릅니다** — 대기는 기다리면 전송되지만 이것은 **기다려도 전송되지 않습니다.**

→ [전송 실패한 기록](공통-화면.md#전송-실패한-기록)에서 이유를 확인하고, 해당 작업 화면에서 **다시 작업하세요.** 그 화면에는 다시 전송하는 버튼이 없습니다.

| 되돌아온 이유                             | 다시 해도 되는가                        |
| ----------------------------------------- | --------------------------------------- |
| `적은 내용에 문제가 있습니다.`            | 같은 값으로는 결과가 같습니다           |
| `다른 곳에서 먼저 바뀌었습니다.`          | 현재 상태를 보고 다시 판단하세요        |
| `지금 상태에서는 할 수 없는 일입니다.`    | 대상이 이미 다음 단계로 넘어가 있습니다 |
| `앞 기록이 가지 못해 붙을 곳이 없습니다.` | 앞의 기록부터 해결해야 합니다           |

처리를 마쳤으면 **목록에서 내리기**로 삭제합니다. 내려도 그 기록이 서버로 전송되지는 않습니다 — 확인했다는 표시일 뿐입니다.
