# 모바일 사용 설명서

현장에서 쓰는 휴대 단말(PDA) 화면의 사용 설명서입니다. 한 손에 단말을 들고 다른 손으로 물건을 다루는 자리에서 쓰도록 만든 화면이라, 화면마다 스캔이 먼저 오고 손으로 치는 입력은 뒤에 옵니다.

이 문서는 화면이 실제로 무엇을 보여 주고 어떤 순서로 무엇을 요구하는지를 적습니다. 사용자가 보는 것만 적으며, 서버나 내부 구조는 다루지 않습니다.

## 시작하기 전에

단말을 처음 켜면 두 가지를 차례로 마쳐야 작업 화면이 열립니다.

1. **기기 등록** — 관리자가 만든 등록 QR을 단말 카메라로 읽습니다. 단말마다 한 번만 합니다.
2. **사번 확인** — 작업자가 자기 사번을 넣습니다. 교대할 때마다 바꿉니다.

자세한 절차는 [공통 화면](공통-화면.md)에 있습니다.

## 여러 화면에 공통으로 적용되는 것

여기 적은 것은 화면 대부분이 같은 방식으로 다루는 항목입니다. 다르게 동작하는 화면은 해당 항목에서 이름으로 짚었고, 자세한 것은 각 화면 설명에 있습니다.

### 화면 위쪽 표시

어느 화면에 있든 위쪽에 세 가지가 늘 보입니다.

- **화면 이름**
- **현재 작업자** — 이름과 사번이 `홍길동 · 100027`처럼 함께 붙습니다. 지금 하는 작업이 누구 이름으로 기록되는지를 뜻합니다.
- **연결 상태** — `온라인` 또는 `오프라인`. 보내지 못하고 쌓인 것이 있으면 `전송 대기 3`처럼 건수가 함께 붙고, 보냈는데 등록되지 않은 것이 있으면 `전송 실패 1`이 붙습니다.

작업자 표시가 다른 사람 사번이면 작업을 시작하기 전에 사번을 바꾸십시오. 기록은 화면에 보이는 사번으로 남습니다.

### 스캔과 직접 입력

라벨을 읽는 칸은 스캐너가 쏘는 값을 받도록 열려 있습니다. 그 칸은 단말 키보드가 올라오지 않게 막아 두었습니다. 화면 절반이 키보드에 덮이면 목록도 단추도 가려지기 때문입니다.

라벨이 훼손되어 스캐너가 읽지 못하면 **직접 입력**을 누르십시오. **칸이 새로 생기지 않고, 방금 그 스캔 칸이 손으로 칠 수 있게 열리며** 키보드가 올라옵니다. 값을 다 치면 아래 단추를 누릅니다. 치는 도중에 스캐너가 값을 쏘면 스캔한 값이 우선합니다.

값을 넣는 단추의 이름은 화면마다 조금씩 다릅니다. 대부분은 **넣기**이고, 무엇을 넣는지 밝혀 적은 화면도 있습니다.

| 이름                                    | 쓰는 화면               |
| --------------------------------------- | ----------------------- |
| **넣기**                                | 대부분의 화면           |
| **찾기**                                | 제품 피킹 · 재생재 등록 |
| **인식표 넣기** · **위치 넣기**         | 제품 입고·적치          |
| **입력한 위치로** · **입력한 LOT 으로** | 적치·입고 완료          |
| **입력한 값으로 찾기**                  | 수리 왕복 스캔          |

스캔한 값을 찾지 못하면 화면에 그 사실이 뜹니다. 대부분의 화면은 여기에 짧은 오류음을 함께 냅니다. 단말을 허리에 매단 채 읽는 자리가 많아, 화면만 보고는 통과한 줄 알고 다음 동작으로 넘어가기 쉬운 탓입니다.

**재고 이동**, **실물 카운트**, **재생재 등록**, **긴급 IQC 생략 요청**은 오류음 없이 화면 표시로만 알립니다. 이 넷을 쓸 때는 스캔한 뒤 화면을 확인하십시오.

### 수량 입력

수량을 넣는 칸은 두 가지 중 하나입니다.

**화면 안의 숫자판** — 대부분의 화면이 이 방식입니다. 장갑을 낀 손으로 조작하는 자리라 키가 촘촘한 단말 키보드가 맞지 않고, 키보드가 올라오면 아래쪽 목록과 완료 단추를 덮기 때문입니다. 칸이 여러 줄인 화면에서는 **지금 값을 넣는 줄 아래에만** 숫자판이 열립니다. 다른 줄을 누르면 숫자판이 그 줄로 옮겨 갑니다.

**단말 숫자 키보드** — **재고 이동**과 **실물 카운트**는 수량 칸을 누르면 단말 키보드가 숫자 배열로 올라옵니다. 키보드가 아래쪽을 덮으므로, 값을 다 치면 키보드를 내린 뒤 완료 단추를 찾으십시오.

### 필수 항목 표시

반드시 채워야 하는 칸은 라벨 뒤에 `(필수)`가 붙습니다. 필수 항목이 비어 있으면 완료 단추가 눌리지 않고, 무엇이 남았는지 화면이 말합니다.

### 단말 뒤로가기

단계를 밟아 나가는 화면에서 단말의 뒤로가기는 화면을 통째로 벗어나지 않고 **가장 최근에 밟은 단계 하나**를 되돌립니다. 예를 들어 대상을 고르고 수량을 넣던 중이면 고른 대상을 내려놓고 다시 고를 수 있는 상태로 돌아갑니다. 되돌릴 단계가 없을 때만 작업 목록으로 나갑니다.

손으로 친 사유나 비고는 뒤로가기로 지워지지 않습니다. 다시 쳐야 하는 부담이 스캔을 다시 하는 것보다 크기 때문입니다.

**입하 등록**, **재고 이동**, **실물 카운트**, **재생재 등록**, **자재 위치 확인**, **전송 실패한 기록**, **기기 등록**에는 이 되돌리기가 없습니다. 뒤로가기 한 번에 작업 목록으로 나가며, 넣던 값은 남지 않습니다. 이 화면들에서는 잘못 넣은 것을 화면 안에서 고쳐야 합니다.

작업 목록에서 뒤로가기를 누르면 앱이 닫힙니다. 보내지 못하고 쌓인 기록은 앱을 닫아도 단말에 남아 있다가 다시 켜면 이어서 보냅니다.

### 연결이 끊겼을 때

공장 안에는 통신이 약한 자리가 있습니다. 화면은 끊긴 상황을 두 가지로 나눠 다룹니다.

**작업을 시작할 때 이미 끊겨 있는 화면** — 저장할 자리가 서버에만 있는 화면은 들어가는 것 자체를 막고 그 사실을 알립니다. 다 해 놓고 저장에서 막히면 작업을 통째로 버리게 되기 때문입니다.

**작업 중에 끊긴 화면** — 스캔한 것과 적은 것을 그대로 두고 저장만 막습니다. 연결이 돌아오면 이어서 하면 됩니다.

**오프라인에서도 기록할 수 있는 화면** — 적은 것을 단말에 넣어 두었다가 연결되면 보냅니다. 이때 화면은 `전송 대기`라고만 말하고 `완료`라고 하지 않습니다. 아직 서버에 가지 않았기 때문입니다. 위쪽 연결 표시의 건수로 몇 건이 남았는지 확인할 수 있습니다.

긴급 요청이나 설비 고장처럼 **사람이 기다리는 기록**은 대기 중이라는 사실을 화면에 계속 띄우고, 급하면 유선으로 함께 알리라고 안내합니다.

### 보냈는데 등록되지 않은 기록

보내기는 했으나 서버가 받지 않은 기록은 기다려도 가지 않습니다. 이런 기록은 `전송 실패`로 따로 세고, [전송 실패한 기록](공통-화면.md#전송-실패한-기록) 화면에서 사유를 확인합니다.

### 되돌릴 수 없는 기록

재고가 움직이거나 기록이 남는 작업은 되돌리는 길이 없습니다. 화면은 그런 자리에서 다음을 지킵니다.

- 완료 단추를 연달아 눌러도 한 건만 나갑니다.
- 수정이나 삭제가 없는 기록은 누르기 전에 그 사실을 묻습니다.
- 같은 대상에 같은 작업이 이미 올라가 있으면 그 사실을 먼저 알립니다.

### 화면 안의 이동

세로가 긴 화면에서는 한 단계를 마치면 다음 단계가 화면 안으로 따라 올라옵니다.

완료 단추는 대부분의 화면에서 아래쪽에 고정되어, 목록이 길어져도 자리를 지킵니다. **입하 등록**, **재고 이동**, **실물 카운트**, **재생재 등록**은 고정하지 않아, 목록이 길면 아래로 끝까지 밀어 내려야 단추가 나옵니다.
