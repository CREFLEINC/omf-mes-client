# 현장 단말(PDA) 사용 설명서

창고와 현장에서 사용하는 휴대용 단말의 사용법입니다. 자재를 받고, 옮기고, 내보내고, 설비를 점검하는 작업을 이 단말로 기록합니다.

한 손으로 단말을 들고 다른 손으로 물건을 다룰 수 있도록 만들어져 있습니다. 그래서 대부분의 화면이 **먼저 스캔하고, 그다음 수량을 입력하고, 마지막에 버튼을 누르는** 순서로 되어 있습니다.

이 설명서는 세 부분으로 나뉘어 있습니다. **위에서부터 읽으시면 됩니다.**

| ---------------------- | ---------------------------- | --------------------------------------------------------------- |

| **작업 중 막혔을 때**  | [막혔을 때](예외-상황.md)    | 상황별 예외 처리. 화면 이름을 몰라도 찾을 수 있습니다            |

이 문서에는 **어느 화면에서나 동일하게 사용하는 조작법**을 정리했습니다. 스캔하는 방법, 수량을 입력하는 방법, 이전 단계로 돌아가는 방법입니다.

## 처음 사용하시는 분께

### 단말을 켜면 나타나는 화면

단말을 켜면 **작업 목록**이 표시됩니다. 여기에서 수행할 작업을 선택합니다.

![작업 목록 화면 전체. 입하·적치·피킹/출고·긴급 요청·실사·생산 이동/수리·출하 스캔·설비·전송 상태 아홉 묶음 아래에 화면 스무 개가 나열되어 있다](images/00-작업목록.png)

작업이 **아홉 개 묶음**으로 나뉘어 있습니다. **입하**는 물건이 들어올 때, **적치**는 보관 위치에 넣을 때, **피킹/출고**는 물건을 꺼내 내보낼 때 사용합니다.

### 작업을 시작하기 전에 반드시 확인할 것

**내 사번이 맞는지 확인하세요.** 화면 맨 위에 현재 작업자의 이름과 사번이 표시됩니다.

![화면 맨 윗줄. 왼쪽에 화면 이름 입하 등록, 가운데에 홍길동 · 100027, 오른쪽에 초록색 온라인 표시가 있다](images/공통-08-머리말.png)

여기에 표시된 사번으로 모든 기록이 남습니다. 단말 하나를 여러 사람이 번갈아 사용하기 때문에, **이전 사용자의 사번이 그대로 남아 있으면 내가 한 작업이 그 사람 이름으로 기록됩니다.**

다른 사람의 사번이라면 [사번 바꾸기](공통-화면.md#사번-확인)를 먼저 하세요.

### 화면 맨 위에 항상 표시되는 세 가지

| 표시              | 뜻                                                   |
| ----------------- | ---------------------------------------------------- |
| 화면 이름         | 현재 어느 화면에 있는지                              |
| `홍길동 · 100027` | 기록이 남을 작업자                                   |
| `온라인`          | 서버와 연결된 상태. 끊기면 `오프라인`으로 바뀝니다   |

전송하지 못한 기록이 있으면 `전송 대기 1`이, 전송했으나 서버가 받지 않은 기록이 있으면 `전송 실패 1`이 옆에 함께 표시됩니다.

![화면 위쪽에 오프라인과 전송 대기 1이 함께 표시된 모습](images/공통-07-전송대기.png)

## 모든 화면에서 공통으로 사용하는 조작

### 1. 스캔하기

라벨을 읽는 입력란은 빨간 테두리로 표시되어 있습니다. 이 입력란에 커서가 있는 동안에는 **스캐너의 스캔 버튼만 누르면** 값이 입력됩니다. 화면을 누르거나 키보드를 열 필요가 없습니다.

![입하 등록 첫 화면. 자재 LOT 라벨을 스캔하세요라는 안내가 있는 빨간 테두리 입력란과 그 아래 직접 입력 버튼](images/01-입하등록-1-스캔.png)

이 입력란을 눌러도 키보드가 올라오지 않습니다. 키보드가 화면 절반을 덮으면 아래쪽 목록과 버튼이 가려지기 때문입니다.

### 2. 라벨이 읽히지 않을 때 — 직접 입력

라벨이 찢어졌거나 오염되어 스캐너가 읽지 못하면 **직접 입력**을 누르세요.

![직접 입력을 누른 뒤. 방금 스캔하려던 입력란이 직접 입력할 수 있게 바뀌고 아래 버튼이 넣기로 바뀌었다](images/공통-03-직접입력.png)

- 입력란이 새로 생기지 않습니다. **방금 스캔하려던 입력란**이 직접 입력할 수 있게 바뀌고 키보드가 올라옵니다.
- 입력을 마치면 아래 버튼을 누릅니다.
- **입력하는 도중에 스캐너로 읽으면 스캔한 값으로 바뀝니다.** 입력하던 내용은 지워집니다.

값을 입력하는 버튼의 이름은 화면마다 조금씩 다릅니다. 대부분 **넣기**이며, 무엇을 입력하는지 구체적으로 적은 화면도 있습니다.

| 버튼 이름                               | 사용하는 화면           |
| --------------------------------------- | ----------------------- |
| **넣기**                                | 대부분의 화면           |
| **찾기**                                | 제품 피킹 · 재생재 등록 |
| **인식표 넣기** · **위치 넣기**         | 제품 입고·적치          |
| **입력한 위치로** · **입력한 LOT 으로** | 적치·입고 완료          |
| **입력한 값으로 찾기**                  | 수리 왕복 스캔          |

### 3. 수량 입력하기

수량을 입력하는 방법은 화면에 따라 두 가지로 나뉩니다.

**화면 안 숫자 키패드** — 대부분의 화면이 이 방식입니다. 수량 입력란을 누르면 바로 그 아래에 숫자 키패드가 열립니다. 장갑을 낀 채로도 누를 수 있는 크기입니다.

![입하 등록의 실입하 수량 입력란과 그 아래 열린 숫자 키패드. 아래쪽에 남은 예정과 맞습니다라는 초록 안내가 있다](images/01-입하등록-5-수량.png)

- `C`는 전체 지우기, `⌫`는 한 자 지우기입니다.
- 여러 줄에 수량을 입력하는 화면에서는 **입력 중인 줄 바로 아래**에만 키패드가 열립니다. 다른 줄을 누르면 키패드가 그 줄로 옮겨 갑니다.

**단말 키보드** — **재고 이동**과 **실물 카운트** 두 화면만 단말 키보드를 사용합니다. 수량 입력란을 누르면 키보드가 올라오며, 이 키보드는 화면 아래쪽을 덮습니다. **입력을 마치고 키보드를 내려야 완료 버튼이 보입니다.**

### 4. 반드시 입력해야 하는 항목

이름 뒤에 `(필수)`가 붙은 항목은 반드시 입력해야 합니다. 비어 있으면 완료 버튼이 눌리지 않으며, 무엇이 비었는지 화면 아래에 안내됩니다.

### 5. 되돌릴 수 없는 기록을 저장할 때

수정하거나 삭제할 수 없는 기록은 저장하기 전에 한 번 더 확인합니다.

![등록하면 고칠 수 없습니다라는 제목의 확인 창. 돌아가기와 등록합니다 두 버튼이 있다](images/공통-04-확인대화.png)

내용을 다시 확인한 뒤 **등록합니다**를 누르세요. **돌아가기**를 누르면 저장되지 않고 이전 화면으로 돌아갑니다.

완료 버튼을 여러 번 눌러도 기록은 한 건만 전송됩니다. 중복으로 기록되지 않습니다.

### 6. 뒤로 가기

단말의 뒤로가기 버튼은 화면 전체를 빠져나가지 않고 **직전 단계만** 되돌립니다. 예를 들어 대상을 고르고 수량을 입력하던 중이라면, 고른 것이 해제되어 대상부터 다시 선택할 수 있습니다. 되돌릴 단계가 없을 때만 작업 목록으로 나갑니다.

직접 입력한 사유나 비고는 뒤로 가도 지워지지 않습니다.

아래 화면들은 이 단계별 되돌리기가 없습니다. 뒤로가기 한 번에 작업 목록으로 나가며 **입력하던 값은 사라집니다.** 잘못 입력한 값은 해당 화면에서 수정하세요.

> 입하 등록 · 재고 이동 · 실물 카운트 · 재생재 등록 · 자재 위치 확인 · 전송 실패한 기록 · 기기 등록

작업 목록에서 뒤로가기를 누르면 **사번 확인 화면**으로 이동합니다. 교대할 때 이 화면에서 사번을 바꾸세요. 여기에서 한 번 더 누르면 앱이 종료됩니다.

전송하지 못한 기록은 앱을 종료해도 단말에 남아 있다가, 다시 실행하면 이어서 전송합니다.

## 연결이 끊겼을 때

공장 안에는 통신이 약한 곳이 있습니다. 연결이 끊기면 화면 위 표시가 `오프라인`으로 바뀝니다. 이때 화면은 세 가지 중 한 가지로 동작합니다.

### 들어갈 수 없는 화면

저장할 내용을 서버에서만 확인할 수 있는 화면은 진입 자체를 막습니다. 작업을 모두 마친 뒤 저장 단계에서 막히면 처음부터 다시 해야 하기 때문입니다.

![제품 피킹 화면. 오프라인이라 피킹할 수 없습니다라는 안내와 다시 시도 버튼](images/공통-06-오프라인차단.png)

연결되는 곳으로 이동한 뒤 **다시 시도**를 누르세요.

해당 화면 — **WIP 공정 이동**, **수리 왕복 스캔**, **제품 피킹**

### 조회만 되지 않는 화면

화면에는 들어갈 수 있지만 목록을 불러오지 못합니다. 이때는 무엇을 불러오지 못했는지 화면에 안내됩니다.

![설비 고장 보고 화면 오프라인 상태. 설비 목록을 불러오지 못했습니다라는 빨간 안내와, 연결되면 알립니다 급하면 직접 연락하세요라는 문구](images/19-설비고장-2-오프라인.png)

### 저장해 두었다가 나중에 전송하는 화면

입력한 내용을 단말에 저장해 두었다가 연결되면 전송합니다. 이때 화면에는 `완료`가 아니라 **전송 대기**로 표시됩니다.

![재생재 등록을 전송 대기에 넣었습니다라는 안내 화면. 위쪽에 오프라인과 전송 대기 1이 보인다](images/공통-07-전송대기.png)

**전송 대기는 아직 서버에 도달하지 않았다는 뜻입니다.** 몇 건이 남았는지는 화면 위 표시로 확인하세요.

긴급 요청이나 설비 고장처럼 **다른 사람이 기다리는 기록**은 대기 중이라는 안내가 화면에 계속 표시됩니다. 급한 경우 유선으로도 함께 알려 주세요.

### 전송했으나 등록되지 않은 기록

`전송 실패`는 `전송 대기`와 다릅니다. 대기는 기다리면 전송되지만, 실패는 **기다려도 전송되지 않습니다.** 원인을 확인하고 해당 작업을 다시 해야 합니다.

→ [전송 실패한 기록](공통-화면.md#전송-실패한-기록)

## 자주 쓰는 용어

| 용어          | 뜻                                                                              |
| ------------- | ------------------------------------------------------------------------------- |
| LOT           | 같은 조건에서 만들어진 한 묶음. 자재·제품마다 번호가 붙습니다                   |
| 자재 LOT 번호 | 공급사가 붙여 온 34자리 숫자                                                    |
| 인식표(HU)    | 제품을 담은 상자나 팔레트에 붙는 QR. 안에 무엇이 몇 개 들었는지 정해져 있습니다 |
| 적치          | 받은 물건을 정해진 보관 위치에 넣는 작업                                        |
| 피킹          | 나갈 물건을 보관 위치에서 꺼내 모으는 작업                                      |
| 보류          | 품질 확인이 끝나지 않아 아직 사용할 수 없는 상태                                |
| ERP W/O       | 구매 발주 번호. 무엇을 얼마나 구매하기로 했는지가 적혀 있습니다                 |
| 남은 예정     | 발주 수량에서 지금까지 받은 수량을 뺀, 앞으로 더 받을 수량                      |
| IQC           | 수입검사. 들어온 자재가 사용 가능한지 확인하는 검사                             |
