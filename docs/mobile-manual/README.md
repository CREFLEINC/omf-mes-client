# 현장 단말(PDA) 사용 설명서

창고와 현장에서 쓰는 손에 드는 단말의 사용법입니다. 자재를 받고, 옮기고, 내보내고, 설비를 점검하는 일을 이 단말로 기록합니다.

한 손에 단말을 들고 다른 손으로 물건을 다루면서 쓰도록 만들어져 있습니다. 그래서 대부분의 화면이 **먼저 스캔하고, 그다음 숫자를 넣고, 마지막에 버튼을 누르는** 순서로 되어 있습니다.

## 이 설명서 읽는 법

세 겹으로 되어 있습니다. **위에서부터 읽으시면 됩니다.**

| 언제                   | 볼 문서                      | 무엇이 있나                                                             |
| ---------------------- | ---------------------------- | ----------------------------------------------------------------------- |
| **처음 배울 때**       | [빠른 시작](00-빠른-시작.md) | 자재가 들어와 제품이 나가기까지 한 바퀴. 이것만 읽어도 일할 수 있습니다 |
| **일하다 막혔을 때**   | [막혔을 때](예외-상황.md)    | 겪는 일로 찾는 예외 모음. 화면 이름을 몰라도 찾을 수 있습니다           |
| **화면 하나를 자세히** | 아래 화면별 문서             | 그 화면의 모든 단계와 모든 메시지                                       |

이 문서(지금 보시는 첫 장)에는 **어느 화면에서나 똑같이 쓰는 조작법**이 있습니다. 스캔하는 법, 숫자 넣는 법, 되돌아가는 법입니다.

## 처음 쓰시는 분께

### 단말을 켜면 나오는 화면

단말을 켜면 **작업 목록**이 나옵니다. 여기서 하려는 일을 골라 들어갑니다.

![작업 목록 화면. 입하, 적치, 피킹/출고, 긴급 요청, 실사 등 묶음별로 화면 이름이 나열되어 있다](images/00-작업목록.png)

일이 묶음별로 나뉘어 있습니다. **입하**는 물건이 들어올 때, **적치**는 자리에 넣을 때, **피킹/출고**는 꺼내 줄 때 씁니다.

### 작업을 시작하기 전에 꼭 하는 것

**내 사번이 맞는지 확인하세요.** 화면 맨 위에 지금 작업자의 이름과 사번이 나옵니다.

![화면 맨 윗줄. 왼쪽에 화면 이름 입하 등록, 가운데에 홍길동 · 100027, 오른쪽에 초록색 온라인 표시가 있다](images/공통-08-머리말.png)

여기 적힌 사번으로 모든 기록이 남습니다. 단말 하나를 여러 사람이 번갈아 쓰기 때문에, **앞사람 사번이 그대로 있으면 내가 한 일이 앞사람 이름으로 기록됩니다.**

다른 사람 사번이면 [사번 바꾸기](공통-화면.md#사번-확인)를 먼저 하세요.

### 화면 맨 위에 늘 보이는 세 가지

| 보이는 것         | 뜻                                                   |
| ----------------- | ---------------------------------------------------- |
| 화면 이름         | 지금 어느 화면에 있는지                              |
| `홍길동 · 100027` | 지금 기록이 남을 작업자                              |
| `온라인`          | 서버와 연결되어 있음. 끊기면 `오프라인`으로 바뀝니다 |

보내지 못한 기록이 있으면 `전송 대기 1`이, 보냈는데 서버가 받지 않은 기록이 있으면 `전송 실패 1`이 옆에 더 붙습니다.

![화면 위쪽에 오프라인과 전송 대기 1이 함께 표시된 모습](images/공통-07-전송대기.png)

## 모든 화면에서 똑같이 쓰는 것

### 1. 스캔하기

라벨을 읽는 자리는 빨간 테두리로 표시되어 있습니다. 여기에 커서가 있는 동안에는 **스캐너 방아쇠만 당기면** 값이 들어갑니다. 화면을 누르거나 키보드를 부를 필요가 없습니다.

![입하 등록 첫 화면. 자재 LOT 라벨을 스캔하세요라는 안내가 있는 빨간 테두리 입력란과 그 아래 직접 입력 버튼](images/01-입하등록-1-스캔.png)

이 자리를 눌러도 키보드가 올라오지 않습니다. 키보드가 화면 절반을 덮으면 아래쪽 목록과 버튼이 가려지기 때문입니다.

### 2. 라벨이 안 읽힐 때 — 직접 입력

라벨이 찢어졌거나 더러워서 스캐너가 못 읽으면 **직접 입력**을 누르세요.

![직접 입력을 누른 뒤. 방금 그 스캔 입력란이 손으로 칠 수 있게 열리고 아래 버튼이 넣기로 바뀌었다](images/공통-03-직접입력.png)

- 입력란이 새로 생기지 않습니다. **방금 그 스캔 자리**가 손으로 칠 수 있게 열리고 키보드가 올라옵니다.
- 다 치면 아래 버튼을 누릅니다.
- **치는 도중에 스캐너로 읽으면 스캔한 값이 들어갑니다.** 치던 것은 지워지니 놀라지 마세요.

값을 넣는 버튼 이름은 화면마다 조금씩 다릅니다. 대부분 **넣기**이고, 무엇을 넣는지 밝혀 적은 화면도 있습니다.

| 버튼 이름                               | 쓰는 화면               |
| --------------------------------------- | ----------------------- |
| **넣기**                                | 대부분의 화면           |
| **찾기**                                | 제품 피킹 · 재생재 등록 |
| **인식표 넣기** · **위치 넣기**         | 제품 입고·적치          |
| **입력한 위치로** · **입력한 LOT 으로** | 적치·입고 완료          |
| **입력한 값으로 찾기**                  | 수리 왕복 스캔          |

### 3. 숫자 넣기

수량을 넣는 방법은 화면에 따라 둘 중 하나입니다.

**화면 안 숫자 키패드** — 대부분의 화면이 이 방식입니다. 숫자를 넣을 자리를 누르면 바로 그 아래에 큼직한 숫자판이 열립니다. 장갑을 껴도 누를 수 있는 크기입니다.

![입하 등록의 실입하 수량 입력란과 그 아래 열린 숫자 키패드. 아래쪽에 남은 예정과 맞습니다라는 초록 안내가 있다](images/01-입하등록-5-수량.png)

- `C`는 전부 지우기, `⌫`는 한 자 지우기입니다.
- 여러 줄에 숫자를 넣는 화면에서는 **지금 넣는 줄 바로 아래**에만 숫자판이 열립니다. 다른 줄을 누르면 숫자판이 그 줄로 따라 옮겨 갑니다.

**단말 키보드** — **재고 이동**과 **실물 카운트** 두 화면만 단말 키보드를 씁니다. 숫자를 넣는 자리를 누르면 키보드가 올라오고, 이 키보드는 화면 아래쪽을 덮습니다. **다 치고 키보드를 내려야 완료 버튼이 보입니다.**

### 4. 꼭 채워야 하는 것

이름 뒤에 `(필수)`가 붙은 자리는 반드시 채워야 합니다. 비어 있으면 완료 버튼이 눌리지 않고, 무엇이 남았는지 화면 아래에 알려 줍니다.

### 5. 되돌릴 수 없는 기록을 저장할 때

고치거나 지울 수 없는 기록은 저장하기 전에 한 번 더 묻습니다.

![등록하면 고칠 수 없습니다라는 제목의 확인 창. 돌아가기와 등록합니다 두 버튼이 있다](images/공통-04-확인대화.png)

내용을 다시 한 번 보고 **등록합니다**를 누르세요. **돌아가기**를 누르면 저장되지 않고 원래 화면으로 돌아갑니다.

완료 버튼을 여러 번 눌러도 기록은 한 건만 나갑니다. 안심하고 누르셔도 됩니다.

### 6. 뒤로 가기

단말의 뒤로가기 버튼은 화면을 통째로 빠져나가지 않고 **방금 한 단계만** 되돌립니다. 예를 들어 대상을 고르고 수량을 넣던 중이라면, 고른 대상을 놓고 다시 고를 수 있는 상태가 됩니다. 되돌릴 단계가 없을 때만 작업 목록으로 나갑니다.

손으로 적은 사유나 비고는 뒤로 가도 지워지지 않습니다.

아래 화면들은 이 되돌리기가 없습니다. 뒤로가기 한 번에 작업 목록으로 나가고 **넣던 값은 사라집니다.** 잘못 넣은 것은 화면 안에서 고쳐 주세요.

> 입하 등록 · 재고 이동 · 실물 카운트 · 재생재 등록 · 자재 위치 확인 · 전송 실패한 기록 · 기기 등록

작업 목록에서 뒤로가기를 누르면 **사번 확인 화면**으로 갑니다. 교대할 때 여기로 와서 사번을 바꾸세요. 거기서 한 번 더 누르면 앱이 닫힙니다.

보내지 못한 기록은 앱을 닫아도 단말에 남아 있다가, 다시 켜면 이어서 보냅니다.

## 연결이 끊겼을 때

공장 안에는 통신이 약한 자리가 있습니다. 끊기면 화면 위 표시가 `오프라인`으로 바뀝니다. 이때 화면은 세 가지 중 하나로 움직입니다.

### 아예 못 들어가는 화면

저장할 내용이 서버에만 있는 화면은 들어가는 것 자체를 막습니다. 다 해 놓고 저장에서 막히면 작업을 통째로 버리게 되기 때문입니다.

![제품 피킹 화면. 오프라인이라 피킹할 수 없습니다라는 안내와 다시 시도 버튼](images/공통-06-오프라인차단.png)

연결되는 자리로 옮긴 뒤 **다시 시도**를 누르세요.

해당 화면 — **WIP 공정 이동**, **수리 왕복 스캔**, **제품 피킹**

### 조회만 안 되는 화면

들어가지기는 하는데 목록을 못 받아 옵니다. 이때는 무엇을 못 받았는지 화면이 알려 줍니다.

![설비 고장 보고 화면 오프라인 상태. 설비 목록을 불러오지 못했습니다라는 빨간 안내와, 연결되면 알립니다 급하면 직접 연락하세요라는 문구](images/19-설비고장-2-오프라인.png)

### 적어 두었다가 나중에 보내는 화면

적은 내용을 단말에 넣어 두었다가 연결되면 보냅니다. 이때 화면은 `완료`라고 하지 않고 **전송 대기**라고 말합니다.

![재생재 등록을 전송 대기에 넣었습니다라는 안내 화면. 위쪽에 오프라인과 전송 대기 1이 보인다](images/공통-07-전송대기.png)

**전송 대기는 아직 서버에 가지 않았다는 뜻입니다.** 몇 건이 남았는지는 화면 위 표시로 확인하세요.

긴급 요청이나 설비 고장처럼 **사람이 기다리는 기록**은 대기 중이라는 사실이 화면에 계속 떠 있습니다. 급하면 유선으로도 함께 알려 주세요.

### 보냈는데 등록되지 않은 기록

`전송 실패`는 `전송 대기`와 다릅니다. 대기는 기다리면 가지만, 실패는 **기다려도 가지 않습니다.** 무엇이 잘못됐는지 확인하고 그 작업을 다시 해야 합니다.

→ [전송 실패한 기록](공통-화면.md#전송-실패한-기록)

## 자주 나오는 말

| 말            | 뜻                                                                              |
| ------------- | ------------------------------------------------------------------------------- |
| LOT           | 같은 조건에서 만들어진 한 묶음. 자재·제품마다 번호가 붙습니다                   |
| 자재 LOT 번호 | 공급사가 붙여 온 34자리 숫자                                                    |
| 인식표(HU)    | 제품을 담은 상자나 팔레트에 붙는 QR. 안에 무엇이 몇 개 들었는지 정해져 있습니다 |
| 적치          | 받은 물건을 정해진 자리에 넣는 일                                               |
| 피킹          | 나갈 물건을 자리에서 꺼내 모으는 일                                             |

| 남은 예정     | 발주한 양에서 지금까지 받은 양을 뺀, 아직 더 받을 양                            |
