# 설비

설비를 점검하고 고장을 알리는 화면입니다. 작업 목록의 **설비**에 있습니다.

| 화면                              | 사용 시점                                   |
| --------------------------------- | ------------------------------------------- |
| [설비 점검](#설비-점검)           | 일상 점검이나 정기 점검 주기가 되었을 때    |
| [설비 고장 보고](#설비-고장-보고) | 가동 중인 설비가 멈추거나 이상음이 날 때    |

> **이 두 화면은 전송하지 못한 기록이 있으면 화면 위에 계속 안내합니다.** 다른 기록과 달리 다른 사람이 이 기록을 보고 조치하기 때문입니다.

---

## 설비 점검

**사용 시점** — 일상 점검 주기나 정기 점검 주기가 되었을 때.

**사전 확인 사항** — 이 기록이 작업 시작을 통제하는 근거입니다. 점검 이력이 없으면 설정에 따라 작업이 막히거나 경고가 표시됩니다. 그래서 전송하지 못한 점검이 있으면 화면 위에 다음과 같이 계속 표시됩니다.

> 전송 대기 중인 점검 3건 — 아직 작업 통제에 반영되지 않습니다

**점검은 확인하는 작업이지 수리하는 작업이 아닙니다.** 불합격이 나오면 보전을 요청하지만, 보전 지시를 이 화면에서 발행하지는 않습니다.

### 순서

![설비 점검 화면 전체. 설비 선택, 점검 유형 일상·정기, 오늘 점검 기록 있음 안내, 항목별 점검 세 항목, 종합과 비고, 점검 완료 버튼](images/18-설비점검-1-설비.png)

**1. 설비를 선택하세요**

설비 QR을 읽거나 **목록에서 고르기**로 선택합니다. 폐기된 설비는 목록에 표시되지 않습니다.

이 공장의 설비가 아닌 코드를 읽으면 `PRS-99 설비를 찾지 못했습니다`가 표시되고 오류음이 함께 납니다.

**2. 점검 유형을 선택하세요**

**일상**과 **정기** 중 하나입니다. 선택하면 오늘 같은 유형으로 점검한 기록이 있는지 함께 표시됩니다.

| 메시지                                          | 뜻                                                                        |
| ----------------------------------------------- | ------------------------------------------------------------------------- |
| `오늘 점검 기록 있음 (09-10 07:12 사번 100027)` | 오늘 이미 점검했습니다. **막지 않습니다** — 다시 점검할지는 직접 판단하세요 |
| `오늘 점검 기록 없음`                           | 아직 점검하지 않았습니다                                                  |
| `오늘 점검 기록을 확인할 수 없습니다`           | 조회하지 못했습니다. 기록이 없다고 단정하지 마세요                        |

**3. 항목마다 판정하세요**

이 설비에 정해진 점검 항목이 순번대로 표시됩니다. 위에 `0 / 3`처럼 몇 개 중 몇 개를 판정했는지 표시됩니다.

항목은 두 가지입니다.

**측정 항목** — 기준이 함께 표시됩니다.

> 1. 유압 압력
>    기준 12 ~ 15 MPa
>    측정값 (필수)

측정값을 입력하면 **화면이 기준과 비교해 자동으로 판정합니다.** 범위 안이면 `합격`, 범위 밖이면 `NG`가 항목 옆에 표시됩니다. **이 판정은 사람이 변경할 수 없습니다.** 범위 밖인데 통과시켜야 하는 경우는 점검이 아니라 별도의 승인 절차로 처리합니다.

기준이 등록되어 있지 않으면 자동 판정이 되지 않고 육안으로 판정합니다 — `기준이 없습니다 — 육안으로 판정하세요`.

**육안 확인 항목** — **합격**과 **NG** 두 버튼이 표시됩니다. 직접 선택하세요.

반드시 판정해야 하는 항목에는 `필수`가 표시됩니다. 항목마다 **항목 비고**를 입력할 수 있습니다.

| 메시지                                                            | 뜻                                                                |
| ----------------------------------------------------------------- | ----------------------------------------------------------------- |
| `이 설비에 점검 항목이 등록돼 있지 않습니다`                      | 점검 대상이 아니거나 항목이 아직 등록되지 않았습니다              |
| `이 유형으로 등록된 점검 항목이 없습니다`                         | 선택한 유형에 해당하는 항목이 없습니다. 다른 유형을 선택해 보세요 |
| `점검 항목을 확인할 수 없습니다. 연결을 확인한 뒤 다시 고르세요.` | 조회하지 못했습니다. 등록되지 않은 것과는 다릅니다                |

**4. 종합을 확인하세요**

합격과 NG 개수가 `합격 6 · NG 1`로 표시됩니다.

NG가 하나라도 있으면 다음과 같이 표시됩니다.

> NG가 있어 보전이 요청됩니다.

그리고 **비고가 필수가 됩니다.**

필수 항목이 남아 있으면 무엇이 남았는지 항목 이름과 함께 표시됩니다 — `점검하지 않은 필수 항목이 있습니다 — 안전커버 파손 여부`.

**5. 점검 완료를 누르세요**

이 버튼은 화면 아래에 고정되어 있어 항목이 많아도 항상 표시됩니다.

### 완료 후

| 결과 | 화면에 표시되는 안내                                                                            |
| ---- | ----------------------------------------------------------------------------------------------- |
| 전송 | `점검을 기록했습니다`                                                                           |
| 대기 | `점검을 전송 대기에 넣었습니다` · `연결되면 보냅니다. 아직 작업 통제에 반영되지 않았습니다.`    |
| 실패 | `점검을 전송하지 못했습니다` · `보냈지만 등록되지 않았습니다. 작업 통제에 반영되지 않았습니다.` |

세 문구 모두 **작업 통제에 반영되었는지**를 함께 안내합니다. 점검을 했는데도 작업이 막히는 상황을 미리 확인할 수 있습니다.

**다른 설비 점검**을 눌러 다음 설비로 넘어갑니다.

## 설비 고장 보고

**사용 시점** — 가동 중인 설비가 멈추거나 이상음이 날 때. **발견 즉시** 사용합니다.

**입력할 항목이 적습니다.** 설비 · 증상 · 발생 상태 세 항목만 입력합니다. 조치하러 가기 전에 현장에서 바로 등록할 수 있습니다. 비가동 사유와 종료 시각은 이 화면에서 받지 않습니다.

**전송하지 못한 보고가 남아 있으면 화면 위에 계속 표시됩니다.**

> 보내지 못한 고장 보고 1건 — 설비담당에게 호출이 가지 않았습니다
> 급하면 직접 연락하세요.

점검과 달리 이 기록은 **다른 사람이 기다립니다.** 전송되지 않으면 설비담당이 오지 않습니다.

### 순서

![설비 고장 보고 화면 전체. 설비 선택과 위치 표시, 이 설비에 처리 중인 고장 1건 안내, 증상 입력란과 지난번 적힌 증상 버튼, 사진 촬영, 발생 상태 두 가지, 설비담당에게 알린다 체크](images/19-설비고장-1-화면.png)

**1. 설비를 선택하세요**

설비 QR을 읽거나 목록에서 선택합니다. 폐기된 설비는 목록에 표시되지 않습니다.

선택하면 그 설비가 **어디에 있는지** 함께 표시됩니다 — `위치 A-01-03 A구역 01열 03단`. 위치 코드와 이름이 함께 표시됩니다.

같은 설비에 아직 처리 중인 고장이 있으면 안내됩니다 — `이 설비에 처리 중인 고장 1건`. **막지 않습니다.** 다른 증상일 수 있으므로 확인하고 판단하세요.

**2. 증상을 한 줄로 입력하세요**

**반드시 입력해야 합니다.**

> 무엇이 어떻게 되었는지 한 줄로 적어 주세요.

예시로 `유압 누유 · 실린더 하부`가 표시됩니다. 글자 수 제한은 없습니다.

같은 설비에 지난번 적은 증상이 있으면 아래에 버튼으로 표시됩니다 — `이 설비에 지난번 적힌 증상`. 누르면 그 문장이 증상 칸에 그대로 들어갑니다.

**3. 필요하면 사진을 첨부하세요**

**촬영 (0/3)**을 눌러 첨부합니다. 최대 세 장입니다.

| 메시지                                                | 뜻                                                         |
| ----------------------------------------------------- | ---------------------------------------------------------- |
| `사진은 세 장까지 붙일 수 있습니다.`                  | 세 장을 모두 첨부했습니다                                  |
| `보내지 못한 사진이 많아 지금은 더 찍을 수 없습니다.` | 아직 전송하지 못한 사진이 쌓여 단말 저장 공간이 부족합니다 |
| `사진을 가져오지 못했습니다`                          | 촬영이 실패했습니다                                        |

**보고 본문이 먼저 전송되고 사진은 뒤따라 전송됩니다.**

**4. 발생 상태를 선택하세요**

반드시 선택해야 합니다.

- **설비가 멈췄다**
- **돌지만 이상하다**

**멈췄다**를 선택하면 **정지 시각** 입력란이 열립니다. **모르면 비워 두세요.** 정지 시각은 선택 항목입니다.

> 비가동 실적은 POP에서 따로 입력합니다.

**돌지만 이상하다**로 변경하면 입력한 정지 시각은 함께 지워집니다.

**5. 알림 체크를 확인하세요**

**설비담당에게 알린다**가 **기본으로 켜져 있습니다.** 이미 전화로 알린 경우에만 해제합니다.

연결이 끊겨 있어도 체크가 자동으로 꺼지지 않습니다. 대신 그 아래에 다음과 같이 표시됩니다.

> 연결되면 알립니다. 급하면 직접 연락하세요.

**6. 고장 보고를 누르세요**

**대기와 실패는 다릅니다.** 대기는 연결되면 전송되지만 실패는 기다려도 전송되지 않습니다.

이 화면은 **접수까지만** 담당합니다. 처리 상태를 변경하는 것은 관리웹에서 합니다.
