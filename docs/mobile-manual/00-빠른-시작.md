# 빠른 시작 — 자재가 들어와 제품이 나가기까지

자재가 공장에 들어와 제품이 되어 나가기까지 **한 바퀴**를 따라가며, 그 사이사이에 단말로 무엇을 하는지 봅니다.

처음 오신 분은 이 문서만 읽으셔도 됩니다. 화면 하나하나를 자세히 봐야 할 때만 아래 링크를 따라가세요.

## 한 바퀴는 이렇게 돕니다

| 단계                                               | 하는 일                               | 단말이 하는 몫 |
| -------------------------------------------------- | ------------------------------------- | -------------- |
| 1 · [자재 받기](#1단계--자재를-받아-자리에-넣는다) | 공급사 자재를 받아 창고 자리에 넣기   | **큽니다**     |
| 2 · [생산 준비](#2단계--생산-계획을-준비한다)      | 무엇을 언제 얼마나 만들지 정하기      | 거의 없음      |
| 3 · [생산 실행](#3단계--생산을-돌린다)             | 자재를 라인에 넣고 만들기             | **큽니다**     |
| 4 · [내보내기](#4단계--제품을-내보낸다)            | 만든 제품을 받아 두었다가 실어 보내기 | **큽니다**     |

**단말이 모든 것을 하지는 않습니다.** 계획을 세우고 판정을 내리는 일은 관리웹에서, 생산 실적은 현장 POP에서 합니다. 이 문서는 **그 사이에 단말이 끼어드는 자리**를 짚습니다.

---

## 시작하기 전에 — 딱 두 가지

**1. 사번이 내 것인지 봅니다.** 화면 맨 위에 나옵니다.

![화면 맨 윗줄. 왼쪽에 화면 이름, 가운데에 홍길동 · 100027, 오른쪽에 초록색 온라인 표시](images/공통-08-머리말.png)

여기 적힌 사번으로 기록이 남습니다. 다른 사람 사번이면 **작업 목록에서 뒤로가기를 한 번 눌러** 사번 확인 화면으로 가서 바꾸세요.

**2. 온라인인지 봅니다.** 오른쪽 표시가 `오프라인`이면 아예 못 하는 일이 있습니다. → [연결이 끊겼을 때](예외-상황.md#연결이-끊겼습니다)

나머지 조작법(스캔·직접 입력·숫자 넣기)은 [공통 사용법](README.md#모든-화면에서-똑같이-쓰는-것)에 있습니다.

---

## 1단계 · 자재를 받아 자리에 넣는다

공급사 차가 도착했습니다. **받아서 → 자리에 넣기**까지가 이 단계입니다.

### 순서

**① 받은 것을 적습니다** — [입하 등록](01-자재창고.md#입하-등록)

자재 LOT 라벨을 스캔하고, 어느 발주 물건인지 고르고, 실제로 받은 양을 넣습니다.

![입하 등록 첫 화면. 자재 LOT 라벨을 스캔하세요라는 빨간 테두리 입력란, 직접 입력 버튼, LOT 번호 없음 버튼](images/01-입하등록-1-스캔.png)

여기서 **입하 기록과 자재 LOT이 한꺼번에 만들어집니다.** 라벨이 붙어 있던 자재는 LOT까지 같이 생깁니다.

**② 자리에 넣습니다** — [적치·입고 완료](01-자재창고.md#적치입고-완료)

받은 자재는 아직 하역장에 있습니다. 내 사번으로 온 적치 지시를 골라, **자리를 먼저 스캔하고 그다음 자재를 스캔**한 뒤 등록합니다.

![적치 지시를 고른 뒤. 권장 위치와 같습니다라는 초록 안내와 ① 적치 위치 ② 자재 LOT 스캔 두 단계](images/07-적치-3-LOT확인.png)

**여기까지 하면 그 자재가 재고로 잡힙니다.** 적치를 안 끝내면 다음 사람이 그 자재를 찾지 못합니다.

### 이 단계에서 자주 갈라지는 길

| 이런 일이 생기면                   | 이렇게 하세요                                                                                              |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 라벨이 훼손돼 스캐너가 못 읽는다   | 화면의 **직접 입력**으로 번호를 칩니다                                                                     |
| 라벨이 아예 안 붙어 있다           | 입하 등록에서 **LOT 번호 없음** → 나중에 [자재LOT 스캔·등록](01-자재창고.md#자재lot-스캔등록)으로 채웁니다 |
| 받은 양이 예정과 다르다            | 화면이 알아서 갈라 줍니다 → [수량이 안 맞습니다](예외-상황.md#수량이-안-맞습니다)                          |
| 가야 할 자리가 꽉 찼거나 못 넣는다 | [임시 위치 적재](01-자재창고.md#임시-위치-적재)로 넘어갑니다                                               |
| 검사를 기다릴 수 없다              | [긴급 IQC 생략 요청](01-자재창고.md#긴급-iqc-생략-요청) — **승인을 받아야 씁니다**                         |

### 단말 밖에서 일어나는 일

- **검사를 받을지 말지**는 등록한 뒤에 줄마다 정해집니다. 단말이 정하지 않습니다.
- 받은 자재는 보통 **보류 상태**로 들어옵니다. 품질에서 풀어 줘야 쓸 수 있습니다.
- 반품할지 폐기할지는 오류를 적어 두면 담당자가 관리웹에서 판단합니다.

## 2단계 · 생산 계획을 준비한다

무엇을 언제 얼마나 만들지 정하는 단계입니다. **관리웹에서 합니다** — `W/O 확정·배포·생산LOT 선발행` 화면입니다.

### 단말이 하는 몫

거의 없습니다. 다만 계획을 준비하는 사람이 창고에 물어볼 때 이 둘을 씁니다.

**필요한 자재가 지금 어디에 얼마나 있는지 보기** — [자재 위치 확인](01-자재창고.md#자재-위치-확인)

라벨을 읽으면 그 자재가 놓인 자리와 수량이 나옵니다. **아무것도 기록되지 않는 화면**이라 마음 놓고 찍어 봐도 됩니다.

![자재 위치 확인 결과. 위치 2곳이라는 안내 아래 창고와 위치별로 보유·가용·예약 수량이 카드로 나열되어 있다](images/06-자재위치-2-결과.png)

**자재를 생산 가까운 창고로 옮기기** — [재고 이동](01-자재창고.md#재고-이동)

반출과 도착을 **두 번에 나눠** 합니다. 물건을 나르는 시간이 그 사이에 있습니다.

### 이 단계가 끝나면

생산에 필요한 자재를 꺼내 달라는 **자재 출고요청**이 만들어집니다. 그것이 창고 단말에 **피킹 지시**로 나타납니다 — 다음 단계입니다.

---

## 3단계 · 생산을 돌린다

계획대로 자재를 라인에 넣고 만드는 단계입니다. 단말이 **창고 쪽과 현장 쪽 양쪽**에서 씁니다.

### 창고에서 — 자재를 골라 낸다

**[자재 출고·피킹](01-자재창고.md#자재-출고피킹)**

내 사번으로 온 피킹 지시를 열면 집을 줄이 나옵니다. 줄마다 **어느 자리에 가서 어느 LOT을 얼마나** 집는지가 적혀 있습니다.

![피킹 라인 목록. 각 줄에 품목, 선출 순위, 요청과 피킹 수량, LOT 번호, 위치가 적혀 있다](images/09-자재출고-2-피킹라인.png)

줄마다 집고 → 다 집었으면 **출고 확정**을 한 번 누릅니다.

### 현장에서 — 받아서 라인에 넣는다

**[생산창고 입고](01-자재창고.md#생산창고-입고)**

창고에서 온 출고 전표를 스캔하고 **실제로 받은 양**을 적습니다. 받은 김에 **호퍼에 남은 양**도 같은 화면에서 적습니다.

![출고 전표를 읽은 뒤. 라인 수령 아래 두 줄의 수령 수량 입력란과 그 아래 호퍼 잔량 부분](images/10-생산창고입고-2-확인.png)

### 만드는 동안 — POP 과 단말이 나눠 맡는다

| 하는 일                   | 어디서                                                 |
| ------------------------- | ------------------------------------------------------ |
| 얼마나 만들었는지 적기    | **현장 POP** — `생산 실적 등록` 화면                   |
| 다음 공정으로 넘기기      | 단말 — [WIP 공정 이동](02-생산이동.md#wip-공정-이동)   |
| 불량을 수리에 넣고 꺼내기 | 단말 — [수리 왕복 스캔](02-생산이동.md#수리-왕복-스캔) |
| 설비 점검하기             | 단말 — [설비 점검](05-설비.md#설비-점검)               |
| 설비가 멈췄을 때 알리기   | 단말 — [설비 고장 보고](05-설비.md#설비-고장-보고)     |

**WIP 공정 이동과 수리 왕복 스캔은 연결이 있어야 합니다.** 끊긴 채로는 화면이 열리지 않습니다.

### 이 단계에서 자주 갈라지는 길

| 이런 일이 생기면            | 이렇게 하세요                                                          |
| --------------------------- | ---------------------------------------------------------------------- |
| 집을 LOT이 보류에 걸려 있다 | 집을 수 없습니다. 화면이 사유와 해제 조건을 함께 보여 줍니다           |
| 요청보다 적게 집었다        | 그대로 확정하면 부족분이 남습니다. 대체 자재는 이 화면에서 안 다룹니다 |
| 받은 양이 출고량보다 적다   | 차이 사유를 꼭 고르세요                                                |
| 설비가 멈췄다               | **발견 즉시** 고장 보고. 셋만 넣으면 끝납니다                          |

## 4단계 · 제품을 내보낸다

만든 제품을 완제품 창고에서 받아 두었다가, 나갈 날에 집어 실어 보내는 단계입니다.

### 순서

**① 만든 제품을 받아 자리에 넣습니다** — [제품 입고·적치](04-출하.md#제품-입고적치)

제품이 담긴 **인식표**를 스캔하고 실제 수량을 적은 뒤, 적치 위치를 스캔합니다.

![인식표를 읽은 뒤 화면. 인수 대상 줄마다 실물 수량과 인식표 수량, 그 아래 적치 위치와 권장 위치](images/15-제품입고-2-인식표.png)

**이 화면에서 받지 않으면 그 제품은 출하 흐름에 들어오지 않습니다.** 뒤에 오는 피킹·검사·출하가 모두 여기서 받은 것을 가리킵니다.

**② 오늘 나갈 제품을 집습니다** — [제품 피킹](04-출하.md#제품-피킹)

오늘 나갈 줄을 고르면 고객이 건 조건과 집을 수 있는 LOT이 순서대로 나옵니다.

![제품 피킹. 피킹 대상 카드와 고객 LOT 요구, 그 아래 권장 LOT 목록이 카드로 나열되어 있다](images/16-제품피킹-2-권장LOT.png)

**고객 LOT 요구는 자유 문장으로 들어옵니다.** 화면이 해석하지 않으니 읽고 직접 판단하세요.

**③ 필요하면 포장을 바꿉니다** — [포장 재구성](04-출하.md#포장-재구성)

합치거나 나누거나 내용을 바꿉니다. **되돌리기가 없습니다.**

### 단말 밖에서 일어나는 일

실제로 차에 싣고 출하를 확정하는 것은 **관리웹**에서 합니다 — `출하 예정 목록`, `출하 처리(상차·실물 출고)`, `출하 확정·취소` 화면입니다. 단말은 **집는 데까지**입니다.

라벨을 뽑는 것도 단말이 하지 않습니다 — **POP** 에서 합니다.

---

## 한 바퀴를 마치고

- 보내지 못한 기록이 남아 있으면 화면 위에 `전송 대기 N`이 붙습니다. **연결되면 알아서 갑니다.**
- `전송 실패 N`이 붙었으면 기다려도 가지 않습니다. → [전송 실패한 기록](공통-화면.md#전송-실패한-기록)
- 교대할 때는 **작업 목록에서 뒤로가기 한 번** → 사번 바꾸기.
