## 제품 입고·적치

**이럴 때 씁니다** — 생산이나 외주에서 넘어온 제품을 완제품 창고에서 받을 때.

**미리 알아 둘 것** — 이 화면에서 받지 않으면 그 제품은 출하 흐름에 들어오지 않습니다. 뒤에 오는 피킹·검사·출하가 모두 여기서 받은 것을 가리킵니다.

제품 LOT을 만드는 것은 생산입니다. 이 화면은 그것을 받아 **자리를 정하는 일**만 합니다.

### 순서

**1. 완제품 창고를 고르세요**

![제품 입고·적치. 입고 창고 1공장 완제품창고가 선택되어 있고, 물건이 들어갈 창고입니다 인식표가 지금 있는 자리와 다를 수 있습니다라는 안내가 있다](images/15-제품입고-1-창고.png)

> 물건이 들어갈 창고입니다. 인식표가 지금 있는 자리와 다를 수 있습니다.

**2. 인식표 QR을 스캔하세요**

읽히면 `인식표 HU-2026-000058`로 확인됩니다. 담긴 물건이 없으면 `이 인식표에는 담긴 물건이 없습니다`가 나옵니다.

**3. 인수 대상을 확인하고 실물 수량을 넣으세요**

![인식표를 읽은 뒤 화면 전체. 이미 입고 처리된 제품 LOT 입니다라는 빨간 안내와 두 줄의 실물 수량, 각각의 인식표 수량과 제조·유효기간, 그 아래 적치 위치와 권장 위치 FG-A-02-01](images/15-제품입고-2-인식표.png)

인식표에 담긴 것이 품목·LOT별로 나옵니다. 줄마다 세 가지가 보입니다.

- `인식표 수량 180` — 인식표가 말하는 수량
- `제조 2026-09-08` · `유효기간 2027-09-10`
- **실물 수량** 자리 — 실제로 받은 양을 넣습니다

인식표 수량과 다르게 넣으면 `인식표 수량과 다릅니다. 실물대로 받습니다.`가 나옵니다. **막지 않습니다. 실물대로 받는 것이 맞습니다.**

검사 대기 중인 LOT이면 이렇게 나옵니다.

> 이 LOT 은 아직 검사 대기입니다. 입고는 되지만 피킹·출하는 막힙니다.

**입고는 막지 않습니다.** 막히는 것은 뒤의 피킹과 출하입니다.

이미 다른 단말이 입고한 LOT이면 막습니다.

> **이미 입고 처리된 제품 LOT 입니다**
> 다른 기기에서 먼저 입고했습니다. 재고를 확인하세요.

연결이 없어 확인하지 못했을 때는 막지 않고 알려 줍니다 — `이미 입고됐는지 확인할 수 없습니다` · `연결이 없어 물어볼 수 없습니다. 재고를 확인한 뒤 진행하세요.`

**4. 적치 위치를 스캔하세요**

스캔하기 전에 **권장 위치**가 먼저 보입니다 — `권장 위치 FG-A-02-01`. 다 스캔한 뒤에 막히면 물건을 들고 되돌아와야 하기 때문입니다.

| 판정               | 화면에 나오는 말                       | 다음                                           |
| ------------------ | -------------------------------------- | ---------------------------------------------- |
| 맞음               | `권장 위치와 같습니다`                 | 넘어갑니다                                     |
| 다름               | `권장 위치 FG-A-02-01 이(가) 아닙니다` | **막힙니다.** 오류음이 함께 납니다             |
| 정해진 자리가 없음 | `이 품목에 정해진 자리가 없습니다`     | **여기 적치합니다**를 눌러 확인하면 넘어갑니다 |

한 인식표에 품목이 여럿이면 권장 위치로 재지 않고 확인을 받습니다.

위치를 관리하지 않는 창고면 스캔하지 않습니다 — `이 창고는 위치를 관리하지 않습니다. 대표 위치로 들어갑니다.` 대표 위치가 없으면 `이 창고에 대표 위치가 없습니다. 관리자에게 문의하세요.`가 나오고 막힙니다.

**5. 입고·적치 완료를 누르세요**

### 완료하고 나면

| 결과            | 화면에 나오는 말                                                                                                           |
| --------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 둘 다 됨        | `입고하고 적치했습니다`                                                                                                    |
| 입고만 됨       | `입고했습니다. 적치가 남았습니다` · `적치 완료는 적치·입고 완료 화면에서 잇습니다.` — **적치 화면으로**를 눌러 이어 가세요 |
| 적치가 되돌아옴 | `입고했습니다. 적치를 전송하지 못했습니다` · 전송 실패한 기록에서 이유를 확인하고 적치 화면에서 다시 하세요                |
| 대기            | `입고를 전송 대기에 넣었습니다` · `연결되면 보냅니다. 적치 완료는 그 뒤 적치 화면에서 잇습니다.`                           |

**입고와 적치는 따로 나옵니다.** 무엇이 되고 무엇이 안 됐는지 보고 다음 할 일을 정하세요.

## 제품 피킹

**이럴 때 씁니다** — 오늘 나갈 제품을 창고에서 집을 때.

**연결이 있어야 합니다.** 보류인지 확인해야 집을 수 있습니다.

![제품 피킹 화면이 오프라인일 때. 오프라인이라 피킹할 수 없습니다 보류 상태를 확인할 수 없습니다라는 안내와 다시 시도 버튼](images/공통-06-오프라인차단.png)

### 순서

**1. 오늘 출하분을 고르세요**

![제품 피킹 첫 화면. 오늘 출하분 아래 SR-2026-0813-0108의 1번 줄과 2번 줄이 카드로 나열되어 있고 각각 배정과 피킹 수량, 남은 배정이 적혀 있다](images/16-제품피킹-1-오늘출하.png)

줄마다 보이는 것

- `배정 300 · 피킹 150` — 배정된 양과 지금까지 집은 양
- `남은 배정 150`
- `배정만큼 다 집었습니다` — 다 채운 줄
- `출하검사 대상` — 검사를 받아야 하는 줄

오늘 나갈 것이 없으면 `오늘 출하할 작업지시가 없습니다`가 나옵니다.

**2. 피킹 대상과 고객 요구를 확인하세요**

![줄을 고른 뒤. 피킹 대상 카드에 고객, 출하 예정, 품목, 배정과 피킹, 남은 배정이 적혀 있고, 그 아래 고객 LOT 요구가 파란 상자로 강조되어 있다. 이어서 권장 LOT 목록이 카드로 나열된다](images/16-제품피킹-2-권장LOT.png)

- `고객 …` · `출하 예정 2026-09-10`
- **`고객 LOT 요구`** — 고객이 LOT에 건 조건입니다. 자유 문장으로 들어오므로 화면이 해석하지 않고 그대로 크게 보여 줍니다. **읽고 직접 판단하세요.**
- `잔여 유효기간 요구 90일 이상`

잘못 골랐으면 **다른 대상 고르기**를 누르세요.

**3. 권장 LOT을 보세요**

집을 수 있는 LOT이 순서대로 나옵니다. 제목에 어떤 순서인지 적혀 있습니다.

- `권장 LOT — 유효기간 이른 순`
- `권장 LOT — 먼저 만든 순`

맨 앞 카드에 `권장 1순위`가 붙습니다. LOT마다 `가용 150 EA`, `유효 2027-01-08`, `잔여 119일`이 보입니다.

앞의 몇 건만 보이며, **목록보기(4)**를 누르면 전체를 봅니다. **돌아가기**로 되돌아옵니다.

집을 수 없는 LOT에는 이유가 붙습니다.

| 메시지                                                    | 뜻                                                                       |
| --------------------------------------------------------- | ------------------------------------------------------------------------ |
| `보류 — 집을 수 없습니다` · `보류 사유 …` · `해제 조건 …` | 보류된 LOT입니다. 무엇을 하면 풀리는지 함께 적혀 있습니다                |
| `다른 출하에 배정됐습니다`                                | 이미 다른 출하가 잡고 있습니다                                           |
| `이 라인의 품목이 아닙니다`                               | 품목이 다릅니다                                                          |
| `고객 요구 90일 미달(실제 60일)`                          | 고객이 요구한 잔여 유효기간에 못 미칩니다                                |
| `유효기간이 없어 잔여 일수를 판정할 수 없습니다`          | 판정할 근거가 없습니다                                                   |
| `권장 1순위가 아닙니다 — 집을 수 있습니다`                | **막지 않습니다.** 권장은 순서 제안이며 다른 것을 집어도 물건은 맞습니다 |

**4. 집을 LOT의 QR을 스캔하세요**

읽히면 `스캔됨 FLOT-2026-0311`로 확인됩니다.

| 메시지                                | 뜻                             |
| ------------------------------------- | ------------------------------ |
| `… LOT을 이 품목에서 찾지 못했습니다` | 그 품목에 없는 번호입니다      |
| `… 은(는) 이 라인의 품목이 아닙니다`  | 있는 LOT이지만 다른 품목입니다 |

**5. 피킹 수량을 넣으세요**

- `피킹 수량은 가용 200 EA을(를) 넘을 수 없습니다`
- `피킹 수량은 남은 배정 80 EA을(를) 넘을 수 없습니다`

**6. 피킹 확정을 누르세요**

`피킹을 기록했습니다`가 나옵니다.

> **확정한 뒤에는 되돌릴 수 없습니다.**

집는 사이에 상태가 바뀌면 `집을 수 없는 상태로 바뀌었습니다. 목록을 다시 확인하세요.`가 나옵니다.

## 포장 재구성

**이럴 때 씁니다** — 포장을 합치거나 나누거나 내용을 바꿀 때.

**물건은 그대로 두고 어느 포장에 들었는지만 바꿉니다.** LOT은 갈리지 않습니다.

> **되돌리기가 없습니다.** 되돌리려면 반대 방향으로 한 번 더 재구성해야 합니다.

**라벨은 여기서 뽑지 않습니다** — `라벨 발행은 POP 에서 합니다. 이 화면은 구성만 바꿉니다.`

### 순서

**1. 원 포장 QR을 스캔하세요**

![포장 재구성 화면 전체. 원 포장 HU-2026-000059 카드와 이미 출하에 배분된 포장입니다라는 빨간 안내, 재구성 유형 세 가지 라디오 버튼, 새 구성 수량 입력란, 남는 것 카드, 이력 보기 링크](images/17-포장재구성-1-원포장.png)

합병이면 **포장 더 스캔**으로 여러 건을 읽습니다. 읽은 수는 `원 포장 2건`으로 보이고, 잘못 읽은 것은 **빼기**로 뺍니다.

| 메시지                                      | 뜻                                                                        |
| ------------------------------------------- | ------------------------------------------------------------------------- |
| `이미 고른 포장입니다`                      | 같은 포장을 두 번 읽었습니다. 두 번 세면 물건이 두 배로 보입니다          |
| `이 포장은 비어 있습니다`                   | 담긴 것이 없습니다                                                        |
| `… 은(는) 이미 출하에 배분된 포장입니다`    | **막힙니다.** 재구성하면 출하에서 이 물건을 찾지 못합니다                 |
| `… 의 출하 배분 여부를 확인하지 못했습니다` | 확인하지 못했습니다. 막지는 않지만 이미 배분된 포장이면 전송이 실패합니다 |

**2. 재구성 유형을 고르세요**

- **합병** — 여러 포장을 하나로
- **분할** — 하나를 여러 개로
- **재구성** — 내용을 바꾼다

여러 포장에서 같은 품목·LOT이 만나면 합쳐지며, 화면이 그 계산을 보여 줍니다 — `80 에 60 을(를) 더해 140 이(가) 됩니다`.

**3. 새 구성 수량을 넣으세요**

품목·LOT마다 새 포장에 담을 수량을 넣습니다. 줄마다 `원 포장 합 120 EA`가 함께 보여 얼마까지 담을 수 있는지 알 수 있습니다.

원 포장에 있는 것보다 많이 담으면 `원 포장에 있는 120 EA 을(를) 넘을 수 없습니다`가 나옵니다.

**4. 남는 것을 확인하세요**

> HU-2026-000059 — 분할 잔량은 원 포장 번호를 그대로 씁니다

**잔량은 새 번호를 받지 않고 원래 번호를 그대로 씁니다.** 잔량 라벨을 새로 뽑지 마세요.

전량을 새 포장으로 옮기면 `원 포장이 비워집니다`가 나옵니다. 정상입니다.

**5. 필요하면 이력을 보세요**

**이력 보기**를 누르면 이 포장을 무엇이 언제 어떻게 바꿨는지 나옵니다. 유형과 시각이 제목으로 나오고 그 아래에 무엇이 얼마에서 얼마로 갔는지가 적힙니다 — `원본 FG-1001 · FLOT-2026-0311 240 → 180`. **원본**은 나간 쪽, **결과**는 들어온 쪽입니다.

재구성한 적이 없으면 `이 포장을 재구성한 적이 없습니다`가 나옵니다. **이력 접기**로 닫습니다.

**6. 재구성 확정을 누르세요**

### 확정하고 나면

| 결과 | 화면에 나오는 말                                                                                 |
| ---- | ------------------------------------------------------------------------------------------------ |
| 보냄 | `재구성을 기록했습니다`                                                                          |
| 대기 | `재구성을 전송 대기에 넣었습니다` · `연결되면 보냅니다. 동기화 후에 POP 대기 목록에 올라갑니다.` |

**오프라인에서 확정하면 POP 대기 목록에 바로 올라가지 않습니다.** 동기화된 뒤에 올라갑니다.
