# 생산 이동·수리

생산 중인 물건을 다음 공정으로 넘기거나, 불량을 수리에 넣고 꺼내는 화면입니다. 작업 목록의 **생산 이동/수리**에 있습니다.

| 화면                              | 이럴 때 씁니다                                  |
| --------------------------------- | ----------------------------------------------- |
| [WIP 공정 이동](#wip-공정-이동)   | 한 공정을 마친 생산 LOT을 다음 공정으로 넘길 때 |
| [수리 왕복 스캔](#수리-왕복-스캔) | 불량을 수리에 넣을 때, 수리를 마치고 꺼낼 때    |

> **두 화면 모두 연결이 있어야 합니다.** 끊긴 채로 들어가면 화면이 열리지 않고, 작업 중에 끊기면 적은 것은 그대로 두고 저장만 막힙니다.

## WIP 공정 이동

**이럴 때 씁니다** — 한 공정을 마친 생산 LOT을 다음 공정으로 넘길 때.

**이어서 하는 작업입니다** — LOT 하나를 넘기고 곧바로 다음 LOT을 읽습니다.

**받는 쪽에서 할 일이 없습니다** — 인계와 수령이 함께 기록되므로 넘기는 쪽에서 한 번만 하면 됩니다.

### 연결이 끊겨 있으면

> **연결이 있어야 할 수 있습니다**
> 공정 인계는 전송 대기에 넣을 수 없습니다. 다음 공정이 무엇인지 확인해야 하기 때문입니다.

다른 화면은 적어 두었다가 나중에 보낼 수 있지만, 이 화면은 다음 공정 목록을 서버에서 받아야 고를 수 있습니다.

작업 도중에 끊긴 경우는 다릅니다. 스캔한 것과 적은 것을 그대로 두고 저장만 막습니다.

> 연결이 끊겼습니다. 적은 것은 그대로 두었으니 연결되면 이어서 하세요.

### 순서

**1. 생산 LOT QR을 스캔하세요**

![WIP 공정 이동. LOT을 읽은 뒤 PLOT-2026-0031 외장 커버 완료 수량 480 EA가 카드로 보이고, 아래에 다음 공정 선택 상자와 인계 수량 입력란, 숫자 키패드가 있다](images/13-WIP이동-1-스캔.png)

읽히면 LOT 번호와 함께 `완료 수량 480 EA`가 보입니다. **여기서 말하는 완료 수량은 계획이 아니라 실제로 만들어 낸 양입니다.**

| 메시지                                                | 이렇게 하세요                                            |
| ----------------------------------------------------- | -------------------------------------------------------- |
| `생산LOT이 아닙니다. 공정 인계는 생산LOT만 넘깁니다.` | 자재 LOT이나 제품 LOT을 읽었습니다. 생산 LOT을 읽으세요  |
| `생산 완료 처리가 필요합니다`                         | 아직 완료로 처리되지 않았습니다. 먼저 완료 처리를 하세요 |
| `보류 중인 LOT입니다`                                 | **막힙니다.** 보류를 먼저 풀어야 합니다                  |
| `완료 수량을 확인할 수 없어 인계할 수 없습니다`       | 완료 수량을 못 받았습니다                                |
| `LOT을 찾지 못했습니다`                               | 읽은 번호가 등록되어 있지 않습니다. 오류음이 함께 납니다 |

재고 이동에서는 보류된 것도 옮길 수 있지만 **공정 인계는 막습니다.** 보류 중인 물건을 다음 공정에 넣으면 불량이 퍼지기 때문입니다.

**2. 다음 공정을 고르세요**

이 LOT이 갈 수 있는 공정이 나옵니다. 공정 이름, 작업지시 번호, 그리고 **그 공정의 상태**가 함께 보입니다 — `사출 (WO-2026-0210) · 진행중`.

| 메시지                                                  | 뜻                                               |
| ------------------------------------------------------- | ------------------------------------------------ |
| `다음 공정이 없습니다. 최종 공정이면 출하로 갑니다.`    | 오류가 아닙니다. 여기서 공정이 끝났다는 뜻입니다 |
| `아직 시작되지 않은 공정입니다. 미리 보낼 수 있습니다.` | 아직 시작 전인 공정입니다. **막지 않습니다**     |

같은 작업지시로는 넘길 수 없습니다.

**3. 인계 수량을 넣으세요**

완료 수량보다 많이 적으면 `완료 수량 480 EA 을(를) 넘을 수 없습니다`가 나옵니다.

**4. 인계 확정을 누르세요**

넘긴 것은 `인계됨 3건` 아래에 `LOT번호 → WO-2026-0210 200 EA`로 쌓이고, 그 위에 이렇게 적힙니다.

> 수령도 함께 기록됐습니다. 받는 쪽에서 따로 확인할 것이 없습니다.

곧바로 다음 LOT을 읽으면 됩니다.

**5. 다 넘겼으면 인계 마치기를 누르세요**

### 실패했을 때

`인계하지 못했습니다`가 뜨고 **다시 보내기**가 나옵니다. 연결이 끊긴 상태에서는 다시 보내기로도 나가지 않습니다.

## 수리 왕복 스캔

**이럴 때 씁니다** — 불량을 수리에 넣을 때(**투입**), 그리고 수리를 마치고 꺼낼 때(**반출**). 한 화면에서 탭으로 나뉩니다.

**연결이 있어야 합니다.** 투입 기록이 서버에 있어야 반출이 그것을 찾아 붙일 수 있습니다.

> **수리한 물건은 원래 LOT으로 돌아가지 않습니다.** 이 화면은 반출까지만 합니다.

### 화면 구성

![수리 왕복 스캔. 위에 불량 LOT 스캔 입력란, 그 아래 수리 투입과 수리 반출 두 탭, 수리할 불량을 고르세요 아래 불량 카드 두 개, 맨 아래 수리 중 1건 표](images/14-수리왕복-2-투입.png)

- 위에 **불량 LOT 스캔** 자리
- 그 아래 **수리 투입** / **수리 반출** 두 탭
- 맨 아래에 아직 반출되지 않은 건이 `수리 중 2건`으로 늘 보입니다

### 수리에 넣는 순서

**1. 불량 LOT 라벨을 스캔하세요**

그 LOT에 달린 불량 기록을 찾습니다. 불량이 여럿이면 고르는 카드가 나옵니다. 카드마다 **불량 코드와 이름**이 제목으로, **수량**이 그 아래에 붙습니다 — `EXT-002 외관 스크래치` · `불량 20 EA`.

불량이 하나뿐이면 자동으로 골라집니다.

고르면 확인 카드에 LOT 번호, 품목코드, 불량 수량, 불량 코드와 이름, 검출 시각이 나옵니다.

| 메시지                                                              | 뜻                                                                              |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `불량 판정된 LOT이 아닙니다` · `최근 180일 안에서 찾았습니다`       | 이 LOT에 불량 기록이 없습니다. **180일보다 오래된 불량은 여기서 찾지 않습니다** |
| `불량 기록을 확인할 수 없습니다. 연결을 확인한 뒤 다시 스캔하세요.` | 조회가 실패했습니다. 불량이 없는 것과는 다릅니다                                |
| `불량 코드를 확인할 수 없습니다`                                    | 코드 이름을 받지 못했습니다                                                     |

**2. 수리 수량을 넣으세요**

불량 수량보다 많이 넣을 수 없습니다.

**3. 투입 등록을 누르세요**

`수리 투입을 기록했습니다`가 뜨고 아래 `수리 중` 목록이 한 건 늘어납니다. 스캔 자리가 비워져 다음 LOT을 바로 읽을 수 있습니다.

같은 불량을 두 번 넣으려 하면 막습니다.

> **이미 수리 투입되었습니다**
> 투입 09-10 09:37

### 수리에서 꺼내는 순서

**1. 반출할 물건의 LOT을 스캔하세요**

스캔하지 않으면 `불량 LOT 을 먼저 스캔하세요`가 나옵니다. 어느 LOT의 건인지 모르면 남의 것을 반출하게 됩니다.

**2. 수리 건을 고르세요**

그 LOT에 열려 있는 수리 건이 수량과 투입 시각으로 나옵니다. 하나뿐이면 자동으로 골라집니다.

열린 건이 없으면 `수리 투입 기록이 없습니다`가 나옵니다.

**3. 수리 결과를 고르세요**

**수리 성공**과 **수리 실패** 중 하나입니다.

**4. 반출 등록을 누르세요**

`수리 반출을 기록했습니다`가 뜨고 아래 `수리 중` 목록에서 그 건이 빠집니다.

### 수리 중 목록

화면 맨 아래에 아직 반출되지 않은 건이 표로 나옵니다. 수리 번호, 수량, 투입 시각이 보입니다. 수리 중인 것이 없으면 `수리 중인 건이 없습니다`가 나옵니다.
