# ds-candidates

DS(`@crefle/web-ui`)에 없어 제품이 만드는 공용 컴포넌트를 격리하는 자리. **DS를 기다리는 대기 목록이 아니라, 기다리지 않기 위한 격리 지대**다 — DS가 구현을 내놓거나 승격이 결정되면 이 폴더 안에서만 교체하면 전 화면에 반영된다.

| 성격 | 대상 | DS 이슈 |
| --- | --- | --- |
| 한시적 대체 — DS 구현 도착 시 폐기 | 행 순서 재배치, 날짜 입력 | #39, #40 |
| 제품 소유 조합물 — 원칙상 DS에 안 올라감 | 읽기 전용 구획+사유, 검색·필터 바, 변경 이력 값 대비, 파일 선택 | #42, #43, #45, #44 |

세 번째 사용처가 생긴 `d` 갭은 DS로 승격한다. 조합물(`c`)을 DS로 올리지 않는다.
